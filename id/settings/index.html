Pengaturan

Selesai menyimpan pengaturan sebagai JSON di dua file: ~/.selesai/agent/settings.json (global, berlaku untuk semua proyek) dan .selesai/settings.json (proyek, menimpa global untuk direktori saat ini). Edit file secara langsung, atau jalankan /settings di dalam sesi untuk mengubah opsi umum secara interaktif.

Halaman ini mencakup pengaturan yang paling sering disentuh orang. Referensi lengkap ada di docs/settings.md di GitHub, dan opsi per ekstensi ada di halaman Kustomisasi.

Model

PengaturanTipeDefaultFungsinya
defaultProviderstring—Provider default, mis. "anthropic" atau "openai".
defaultModelstring—ID model default untuk sesi baru.
defaultThinkingLevelstring—Seberapa banyak agent berpikir sebelum menjawab: "off", "minimal", "low", "medium", "high", atau "xhigh".
enabledModelsstring[]—Pola model untuk perpindahan Ctrl+P, mis. ["claude-*"].

Tool

PengaturanTipeDefaultFungsinya
defaultToolsstring[]—Pemilihan tool bawaan awal untuk sesi baru. Saat disetel, sesi baru hanya mengaktifkan tool ini (berguna bersama SDK); saat dihilangkan, read, bash, edit, write default dipakai.

Tampilan

PengaturanTipeDefaultFungsinya
themestring"dark""dark", "light", atau nama tema kustom. Anda juga bisa mengatur tema awal untuk satu sesi dengan --use-theme <nama>.
quietStartupbooleanfalseSembunyikan header startup agar peluncuran lebih tenang.
tuiModestring"fullscreen""fullscreen" (tata letak dock default) atau "regular" (tata letak Pi klasik).
fullscreenExitOutputstring"transcript"Yang terjadi saat keluar dari fullscreen: mencetak transkrip ("transcript") atau hanya petunjuk resume sesi ("resume-hint").
powerlinestring"default"Preset status bar untuk footer powerline: "default", "minimal", "compact", "full", "nerd", atau "ascii".

Konteks

PengaturanTipeDefaultFungsinya
compaction.enabledbooleantrueKompakkan otomatis konteks lama saat percakapan membesar.
compaction.reserveTokensnumber16384Token yang disisakan untuk balasan model.
compaction.keepRecentTokensnumber20000Token terbaru yang tidak pernah diringkas.

Kepercayaan dan keamanan

PengaturanTipeDefaultFungsinya
defaultProjectTruststring"ask"Fallback untuk mempercayai proyek pada run non-interaktif: "ask", "always", atau "never". Hanya pengaturan global.

Ekstensibilitas

PengaturanTipeDefaultFungsinya
packagesarray[]Package npm/git yang memuat ekstensi, skill, prompt, dan tema.
extensionsstring[][]File atau direktori ekstensi lokal yang dimuat.
skillsstring[][]File atau direktori skill lokal yang dimuat.

Tempat pengaturan berada

LokasiCakupan
~/.selesai/agent/settings.jsonGlobal — berlaku untuk semua proyek.
.selesai/settings.jsonProyek — menimpa nilai global untuk direktori saat ini.

Objek bersarang digabungkan, sehingga file proyek hanya perlu menimpa kunci yang diinginkan.

Reset pabrik

Untuk mengembalikan pengaturan global ke default pabrik bawaan, jalankan /settings-factory-reset di dalam sesi. Perintah ini memberi peringatan sebelum mengganti ~/.selesai/agent/settings.json, menyimpan cadangan .bak di samping file, dan tidak menyentuh kredensial (auth.json), sesi, ekstensi, skill, maupun tema.

Satu contoh gabungan

Untuk daftar lengkap semua pengaturan, lihat docs/settings.md. Untuk konfigurasi tingkat ekstensi, lihat halaman Kustomisasi.
