## Comparison badges

- **Selesai difference** — a capability that changes how work is structured compared with Pi baseline usage.
- **Bundled** — a capability that Selesai ships in-tree and tests as part of the release.
- **Ergonomics** — small but commonly requested improvements that reduce friction or token spend.
