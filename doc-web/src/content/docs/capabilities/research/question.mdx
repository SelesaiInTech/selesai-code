The `question` extension provides a terminal wizard for asking the user one or more typed questions. It supports single-select, multi-select, free-form text, and context/info-only questions, with keyboard navigation and filtering.

## Setup and prerequisites

- This extension is bundled with Selesai. It is loaded automatically; you do not need to install it separately.
- Requires terminal TUI mode. It cannot be used in headless or non-interactive sessions.
- The agent invokes the tool; the user answers through the TUI.

## What it sets up

- Registers the `question` tool and renders a full-screen batch question component.
- Each question has a stable `id`, a `label`, a `question` string, a `type`, and optional `options` and `context`.
- Answers are returned as a structured result with `answered`, `skipped`, and `unanswered` statuses.

## What you can configure

- No user-facing configuration. The question schema is fixed by the tool definition.

## What you can do

- Ask independent decisions that the user must make directly.
- Present single-select, multi-select, text, or info-only questions.
- Provide stable option `value`s separate from human-readable `label`s.

## Commands, tools, and shortcuts

There are no slash commands. The tool is invoked by the agent:

```json
question({
  questions: [
    {
      id: "target_db",
      label: "Database",
      type: "select",
      question: "Which database should we use?",
      options: [
        { value: "sqlite", label: "SQLite" },
        { value: "postgres", label: "PostgreSQL" }
      ],
      allowOther: true
    },
    {
      id: "skip_cache",
      label: "Skip cache",
      type: "text",
      question: "Why skip the cache?"
    }
  ]
})
```

Supported question types: `select`, `multiselect`, `text`, `image`, `info`.

When reviewing, the user can move between questions with `Tab`/`Shift+Tab`, leave a text question blank to skip it, and press `Enter` on the review screen to submit the final answers.

## Limits and safety

- The tool only works in TUI mode. Invoking it from a non-interactive session throws an error.
- Questions should be independent decisions that the user must make; the agent should inspect facts itself rather than asking the user for discoverable information.
- `info` questions are context-only and do not require a response.
- Blank text entries are recorded as `skipped`; the agent must handle skipped and unanswered statuses explicitly.
