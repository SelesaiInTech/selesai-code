## What it is and why it helps

`ponytail` is a family of communication modes and review helpers that make agent responses minimal, compressed, and focused. Invoke it with `/skill:ponytail` or related variants such as `/skill:ponytail-review`, `/skill:ponytail-audit`, `/skill:ponytail-gain`, `/skill:ponytail-debt`, and `/skill:ponytail-help`.

## Availability

Included in `@selesai/code` as the `ponytail` extension and the `ponytail*` skills in `src/skills/`.

## Quick start

```sh
/skill:ponytail
```

For a review:

```sh
/skill:ponytail-review
```

## Configuration

No separate configuration is required. The skill changes how the agent formats and scopes its responses.

## Limits and edge cases

- Ponytail modes reduce verbosity; complex explanations may need to be requested explicitly.
- Variants are tuned for specific tasks; choose the variant that matches the current goal.
