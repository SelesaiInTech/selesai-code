# Turn-level undo

## What it is and why it helps

The `undo` extension gives you turn-level undo for tracked edits, writes, and detected mutating shell commands. If the agent makes an unexpected change, you can roll back one step at a time.

## Availability

Included in `@selesai/code` as `src/extensions/undo.ts`.

## Quick start

```sh
/undo
```

## Configuration

No separate configuration is required. The extension tracks mutations made by the agent during the session and exposes them as undoable turns.

## Limits and edge cases

- Only tracked edits, writes, and detected mutating shell commands can be undone.
- Undo works one turn at a time; earlier non-mutating turns do not affect file state.
- If a shell command is not recognized as mutating, it will not be part of the undo stack.
