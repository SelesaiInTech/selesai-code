## What it is and why it helps

The `copy-turn` extension lets you copy a user or assistant result from the session by hash, so you can paste it elsewhere without re-typing long outputs.

## Availability

Included in `@selesai/code` as `src/extensions/copy-turn.ts`.

## Quick start

```sh
/cp <hash>
```

## Configuration

No separate configuration is required.

## Limits and edge cases

- You need the hash of the target turn. Hashes are displayed by the Selesai session UI.
- The copied content goes to the system clipboard; it may be overwritten by later copies.
