# Context reminder

## What it is and why it helps

The `context-compaction-reminder` extension warns you when a conversation grows large and suggests a `/handoff-new` before quality degrades or costs rise further.

## Availability

Included in `@selesai/code` as `src/extensions/context-compaction-reminder.ts`.

## Quick start

When a reminder appears, use it as the signal to reset context:

```sh
/handoff-new
```

## Configuration

No separate configuration is required. The reminder triggers based on session size heuristics.

## Limits and edge cases

- The reminder is advisory; you choose whether to hand off.
- If you ignore it, token cost may increase and response quality may degrade.
