Automatic model routing is a bundled extension that classifies each eligible user prompt and selects a configured model for one of four difficulty tiers. It is disabled by default so model selection remains unchanged until you opt in.

## Setup and prerequisites

- The extension ships with Selesai and loads automatically; no separate installation is required.
- Configure at least one available `provider/model` target for a tier. Targets are limited to the models visible in the current session scope.
- Enable it with `/auto-model-settings enable` after reviewing the configuration.

## What it sets up

- A classifier assigns eligible prompts to `simple`, `medium`, `complex`, or `reasoning`.
- The extension switches to the configured tier target before the prompt is processed, and keeps the current model when a target is unset or unavailable.
- Configuration is layered globally at `~/.selesai/agent/extensions/auto-model/config.json` and, for trusted projects, at `.selesai/extensions/auto-model/config.json`; project values override global values.

## What you can configure

<ExtensionCustomization slug="auto-model" locale="en" />

The default classifier is an LLM with a 3-second timeout and three prior user turns (300 characters per turn). Set `classifier` to `heuristic` to avoid a classifier model call, or configure an available classifier `provider/model`.

## What you can do

- Enable or disable routing and inspect the effective settings.
- Assign distinct models to all four tiers, using global or trusted-project scope.
- Test classification without switching models.

## Commands, tools, and shortcuts

Use the bundled slash command:

```text
/auto-model-settings show
/auto-model-settings enable
/auto-model-settings disable
/auto-model-settings set simple provider/model
/auto-model-settings classifier heuristic
/auto-model-settings test explain this change
```

In the TUI, `/auto-model-settings` without arguments opens tier and model pickers. Add `--project` to write trusted-project settings; otherwise the command writes the global layer. `/auto-model-settings set` accepts only an available, in-scope model.

## Limits and safety

- Routing is disabled by default.
- Automatic routing runs for interactive or RPC input while the session is idle; extension input, queued/streaming input, and input received while the agent is busy are not routed. Inputs are serialized, so concurrent prompt routing is not independently guaranteed.
- Manual model selection suspends routing until `/auto-model-settings enable` is used. Restored model selections do not create a new suspension.
- The classifier receives the current prompt plus up to the configured recent user-context limit. Classifier failures and timeouts fall back to local heuristic classification; no target switch occurs when the selected tier has no available model.
