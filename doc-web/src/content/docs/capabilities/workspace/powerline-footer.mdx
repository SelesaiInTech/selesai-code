## What it is and why it helps

The `pi-powerline-footer` extension upgrades the terminal workspace with a powerline status bar, fixed-editor layout, recurring `/guide` tour, persistent bash, editor stash/restore, and themed working-vibe messages.

## Availability

Included in `@selesai/code` as `src/extensions/pi-powerline-footer/`.

## Quick start

In an interactive Selesai session, look at the bottom of the terminal:

```sh
selesai
```

The status bar shows model, thinking level, path, git state, context, tokens, cost, cache, and session data.

## Configuration

No separate configuration is required. The footer adapts to the project state and supports configurable presets.

## Limits and edge cases

- Requires a terminal that supports the chosen font and Nerd Font glyphs for the best experience.
- Persistent bash state is local to the Selesai session.
- The `/guide` tour can be dismissed and will remember dismissal.
