The `pi-powerline-footer` extension customizes Selesai's native fullscreen terminal UI with a powerline-style status bar, recurring guide tour, editor stash/history shortcuts, sticky bash mode, file-backed queue/inbox, session-aware directory switching, AI-generated working vibes, and Nerd Font detection.

## Setup and prerequisites

- This extension is bundled with Selesai. It is loaded automatically; you do not need to install it separately.
- Requires an interactive TUI session. It has no effect in headless mode.
- Nerd Font is recommended for the `nerd` preset but not required; the `ascii` preset is safe for any terminal.
- Sticky bash mode needs a POSIX-compatible shell.

## What it sets up

- Replaces the default footer/header/editor chrome with powerline-styled segments.
- Registers the `/powerline`, `/guide`, `/stash-history`, `/bash-mode`, `/bash-reset`, `/vibe`, `/idea`, `/ideas`, `/queue`, and `/cd` commands.
- Adds a file-backed queue and idea inbox so you can capture thoughts or safely hold prompts through compaction without interrupting the current agent.
- Registers keyboard shortcuts for editor stash, copy/cut, bash-mode toggle, and stash history.
- Its status, editor, and widgets render inside Pi's native fullscreen dock while the transcript scrolls independently.

## What you can do

- Toggle powerline on/off: `/powerline`.
- Switch preset: `/powerline nerd`.
- Fullscreen is Selesai's default; set `"tuiMode": "regular"` to opt out.
- Scroll the native transcript with a mouse wheel or trackpad.
- Open the recurring guide: `/guide` (compact by default; use `/guide full`, `/guide compact`, `/guide off`, or `/guide reset`).
- Stash or restore editor text: `Alt+S`.
- Open prompt history: `Ctrl+Alt+H` or `/stash-history`.
- Copy full editor text: `Ctrl+Alt+C`. Cut: `Ctrl+Alt+X`.
- Toggle sticky bash mode: `Ctrl+Shift+B` or `/bash-mode on|off|toggle`.
- Reset the managed shell: `/bash-reset`.
- Set a working vibe theme: `/vibe star trek` or `/vibe off`.
- Capture a deferred idea: `# <idea>` or `/idea <idea>`; browse or send it with `/ideas`.
- Inspect, retry, retarget, or deliver held prompts with `/queue`.
- Continue the current conversation from another directory with `/cd <path>`.
- Arrange segments, separators, placement, welcome screen, and cost display through `powerline` settings.

| Command / shortcut | Description |
| --- | --- |
| `/powerline` | Toggle the powerline UI. |
| `/powerline <preset>` | Switch status preset. |
| `/cd [path]` | Show or change the current session directory. |
| `/idea [@target] <text>` | Save a deferred idea without sending it to the current agent. |
| `/ideas [next\|send\|issue]` | Browse saved ideas, deliver one, or hand one to the agent for guarded issue triage. |
| `/queue [send\|retry\|clear\|target]` | Browse and manage queued or blocked prompts. |
| `/guide [full\|compact\|off\|reset]` | Open, compact, dismiss, or reset the recurring guide. |
| `/stash-history` | Open the prompt history picker. |
| `/bash-mode on\|off\|toggle` | Toggle sticky bash mode. |
| `/bash-reset` | Reset the managed shell session. |
| `/vibe [theme\|off\|mode\|model\|generate]` | Configure working-message vibes. |
| `Alt+S` | Stash or restore editor text. |
| `Ctrl+Alt+H` | Open stash/prompt history. |
| `Ctrl+Alt+C` | Copy full editor text. |
| `Ctrl+Alt+X` | Cut full editor text. |
| `Ctrl+Alt+Q` | Open the queued-prompt picker. |

| Mouse wheel / trackpad | Scroll the native transcript, including while the pointer is over the dock. |

| `Home` / `End` | Navigate the transcript in fullscreen mode. Use `Ctrl+Home` / `Ctrl+End` for the editor. |

## Limits and safety

- The powerline UI only renders in interactive TUI sessions.
- Sticky bash mode keeps a managed shell for the current Selesai session. Shell `cd` and exported variables persist across commands, but the shell and its transcript are lost when the session ends.
- `# <idea>` captures an idea only when `#` is followed by whitespace; set `powerline.queue.captureSigil` to `false` if markdown headings are more common, then use `/idea` instead. Prompts held during compaction are delivered only after successful compaction; failed or cancelled work remains visible in the queue.
- Generated vibe messages use the configured model and are rate-limited. Pre-generate vibe files with `/vibe generate <theme> <count>` to avoid API latency and cost.
- Powerline does not own terminal scrolling; select `"tuiMode": "regular"` if your terminal is incompatible with fullscreen mode.
- Custom shortcut conflicts with reserved keys are automatically resolved to safe defaults.
