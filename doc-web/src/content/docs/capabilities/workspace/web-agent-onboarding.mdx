The `web-agent-onboarding` extension runs on the first interactive Selesai startup and offers to configure Brave Search for the bundled `pi-web-agent`. If you decline, the agent falls back to the default DuckDuckGo backend.

## Setup and prerequisites

- This extension is bundled with Selesai. It is loaded automatically; you do not need to install it separately.
- Only runs during the first startup (`event.reason === "startup"`) until the onboarding marker is written.
- Requires an interactive TUI session to show the confirmation and paste prompts.
- Network access to `https://api-dashboard.search.brave.com/app/keys` is needed if you choose to open the Brave dashboard.

## What it sets up

- Writes `~/.selesai/agent/.webAgentOnboardingComplete` once onboarding is complete or explicitly skipped.
- If you opt in, saves `webAgent.braveApiKey` in `~/.selesai/agent/settings.json`.
- Writes a global backend config selecting Brave with DuckDuckGo fallback under `~/.selesai/agent/extensions/pi-web-agent/config.json`.
- Triggers an extension reload so the `pi-web-agent` backend re-reads the new config.

## What you can do

- Accept the first-run prompt to use Brave Search. It opens the Brave API key dashboard, lets you paste the key, and switches `pi-web-agent` to Brave automatically.
- Decline the prompt to keep the DuckDuckGo backend.
- Run `/setup-web-search` at any time to rerun the flow.

## Commands, tools, and shortcuts

| Command | Description |
| --- | --- |
| `/setup-web-search` | Re-run the Brave Search onboarding flow, then reload extensions if a key is saved. |

## Limits and safety

- The onboarding marker prevents the prompt from appearing again even if you skip or cancel. Use `/setup-web-search` to rerun it.
- Brave keys are stored in `~/.selesai/agent/settings.json`. Do not commit that file or share the key.
- If Brave is not available in your region or the key is invalid, `pi-web-agent` can still fall back to DuckDuckGo when `fallback: "duckduckgo"` is configured.
