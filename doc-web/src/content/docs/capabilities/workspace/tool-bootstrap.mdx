Selesai initially exposes only its bootstrap tool surface, then enables the standard read-only tools after the first durable tool call. Preview-export tools remain unavailable to agents while Markdown preview rendering continues to work.

## Setup and prerequisites

This behavior is bundled and automatic. No setup or configuration is required.

## What it sets up

- Enables the standard read-only tool catalog after bootstrap.
- Keeps preview-export tools hidden from the agent tool surface.

## What you can configure

There is no user-facing setting. Tool visibility is source-defined.

## What you can do

Use the normal read-only tools after the bootstrap call without manually enabling an extension.

## Commands, tools, and shortcuts

There are no commands or shortcuts for these internal bootstrap extensions.

## Limits and safety

The bootstrap call must complete before the full standard catalog is exposed. Hiding preview-export tools affects only agent tool visibility; it does not disable Markdown preview rendering.
