# Token onboarding

## What it is and why it helps

The `tokenin-onboarding` extension guides first-time users through provider credential and API token setup so Selesai can talk to model providers without editing configuration files by hand.

## Availability

Included in `@selesai/code` as `src/extensions/tokenin-onboarding.ts`.

## Quick start

On first run, Selesai prompts for provider credentials. To re-run the onboarding:

```sh
/tokenin-onboard
```

## Configuration

Follow the interactive prompts to choose a provider and paste an API key. Selesai stores credentials in the standard config location.

```sh
# Typical first-run flow
selesai
# Follow the tokenin prompts to add your provider key
```

## Limits and edge cases

- Keep API keys secret. Do not commit them to version control.
- Provider keys may require billing to be enabled.
- If a provider is not available, first check that the key was pasted correctly and is active.
