Selesai bundles an OpenAI-compatible Ollama provider for local models.

## Setup and prerequisites

- Install and run Ollama locally.
- The provider is shipped automatically with `@selesai/code`.

## What it sets up

- Registers the bundled local Ollama provider and its model catalog integration.

## What you can configure

<ExtensionCustomization slug="custom-provider-ollama" locale="en" />

## What you can do

- Select local Ollama models through the normal model selector and refresh catalog flows.

## Commands, tools, and shortcuts

Use the standard model selector and `/settings`; the extension adds no dedicated slash command.

## Limits and safety

Local model behavior, availability, and hardware requirements are provided by Ollama and the selected model.
