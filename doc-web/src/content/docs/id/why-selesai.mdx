Selesai adalah fork dari [Pi coding agent](https://github.com/earendil-works/pi). Selesai mempertahankan inti terminal-first yang dapat di-*hack* dan menambahkan satu set extension, skill, serta perbaikan ruang kerja yang terkoordinasi. Halaman ini memisahkan apa yang sudah disediakan Pi dari apa yang ditambahkan atau dibundel Selesai, serta menautkan setiap klaim material Selesai ke bukti.

## Apa yang sudah dilakukan Pi

Pi tetap menjadi harness coding kecil dan mumpuni. Selesai mempertahankan kemampuan dasar ini:

- coding interaktif terminal-first dengan `read`, `bash`, `edit`, `write`, `grep`, `find`, dan `ls`;
- beberapa model provider, API key, OAuth, thinking level, gambar, dan retry;
- sesi persisten dengan resume, fork, navigasi tree, compaction, dan export;
- mode print, JSON event-stream, dan RPC;
- extension TypeScript, skill, template prompt, tema, package, dan SDK Node.js yang dapat di-*embed*;
- project trust dan resource loading yang dapat dikonfigurasi.

## Mengapa *bundling* penting

Pi memiliki ekosistem extension yang luas. Memasang banyak package terpisah berarti harus melacak pemeliharaan, kompatibilitas, dan batas supply-chain-nya. Selesai membawa extension yang mendefinisikan pengalaman Selesai di `src/extensions/`, mengujinya bersama aplikasi, dan mengirimkannya bersama setiap rilis.

Ini membuat source tetap terlihat, dapat direview, dan diaudit di satu tempat. Ini tidak menghilangkan risiko supply-chain — Selesai masih memiliki runtime dependencies — tetapi menghilangkan kebutuhan untuk memasang banyak extension tidak terkait sebelum Selesai menjadi berguna.

## Hasil praktis

- **Lebih sedikit gesekan setup:** instal `@selesai/code` dan dapatkan subagent, workflow, riset web, pertanyaan interaktif, tool recovery, skill, dan UI yang lebih kaya dalam satu package.
- **Pengeluaran token lebih kecil:** `/handoff-new`, pengingat konteks, dan footer powerline membantu menjaga konteks tetap kecil dan fokus.
- **Pemulihan lebih baik:** rewind yang didukung git, undo per turn, dan handoff sesi mengurangi biaya kesalahan.
