## Instal Selesai

Gunakan npm untuk memasang package secara global. Izinkan lifecycle script berjalan agar Selesai dapat memasang dan mengonfigurasi aset bawaannya dengan benar.

<InstallCommand command="npm install -g @selesai/code" />

Package yang dipublikasikan adalah `@selesai/code` dan binarinya adalah `selesai`.

Untuk memasang langsung dari repositori publik (membangun `main` terbaru dari source):

<InstallCommand command="npm install -g github:SelesaiInTech/selesai-code" />

## Sering perbarui

Selesai dan ekosistem Pi berkembang cepat. Perbaikan penting, kemampuan baru, dan perubahan perilaku dapat hadir setiap hari, jadi sering perbarui instalasi Anda:

<InstallCommand command="npm install -g @selesai/code@latest" />

## Jalankan Selesai

<InstallCommand command="selesai" />

Untuk satu kali pakai tanpa instalasi global:

<InstallCommand command="npx @selesai/code" />

## Perintah pertama

```sh
# Minta agen menjelaskan codebase
selesai "Explain this repository and tell me how to run its checks"

# Permintaan sekali pakai, read-only
selesai -p "Review the current git diff without editing files"
```

## Lokasi konfigurasi

selesai menyimpan status di dua tempat:

- `~/.selesai/agent/` — status dan resource tingkat user
- `./.selesai/` — pengaturan dan resource tingkat project

Kredensial sensitif seperti API key ditangani melalui token onboarding dan konfigurasi provider. Tambahkan kredensial provider dengan hati-hati dan hindari meng-*commit*-nya ke version control.

## Ekspor kredensial terkonfigurasi

Gunakan perintah `auth` eksplisit ketika client eksternal memerlukan kredensial yang sudah dikonfigurasi di Selesai:

```sh
selesai auth print-api-key --provider openai --model gpt-5.5
selesai auth print-bearer-token --provider openai-codex --model gpt-5.5
```

Perintah ini mencetak secret langsung ke stdout. Hindari log terminal, shell tracing, command substitution di environment bersama, dan file output yang dikomit. OAuth bearer token di-refresh otomatis jika sisa masa berlakunya terlalu pendek.
