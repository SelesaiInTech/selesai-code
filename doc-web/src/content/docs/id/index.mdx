# Selesai

Selesai adalah fork yang dikelola dari [Pi coding agent](https://github.com/earendil-works/pi), dengan pendekatan *extension-first*. Selesai mempertahankan *harness* coding kecil dan dapat di-hack dari Pi, lalu mengirimkan satu set extension, skill, dan perbaikan tampilan terkoordinasi sebagai bagian dari aplikasi.

Tujuannya sederhana: membuat coding agent yang mampu langsung berguna, memaksimalkan pemanfaatan token, dan mendapatkan hasil setara atau lebih baik dengan lebih sedikit token dan biaya lebih rendah — tanpa mengharuskan setiap pengguna memasang dan mempercayai banyak sekumpulan extension tidak terkait.

## Mulai menggunakan Selesai

```sh
# Tanyakan pertanyaan
selesai "Explain this repository and tell me how to run its checks"

# Review sekali pakai
selesai -p "Review the current git diff without editing files"
```

## Jelajahi kemampuan
