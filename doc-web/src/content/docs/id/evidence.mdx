Setiap klaim perbandingan dan deskripsi kemampuan di situs ini ditautkan kembali ke repositori source Selesai. Kami menjadikan source sebagai bukti utama.

## Sumber bukti

| Jenis | Lokasi |
| --- | --- |
| Metadata package dan instal | [`package.json`](https://github.com/SelesaiInTech/selesai-code/blob/main/package.json) |
| Posisi publik dan perbandingan Pi | [`README.md`](https://github.com/SelesaiInTech/selesai-code/blob/main/README.md) |
| Manifest extension dibundel | [`src/extensions/package.json`](https://github.com/SelesaiInTech/selesai-code/blob/main/src/extensions/package.json) |
| Perilaku kemampuan | Directory source extension, entry module, tests, dan `README.md` masing-masing |
| Skill | [`src/skills/`](https://github.com/SelesaiInTech/selesai-code/blob/main/src/skills/) |
| Riwayat rilis | `CHANGELOG.md` bila ada |

## Pemetaan bukti kemampuan

| Kemampuan | Jalur source | Tautan bukti |
| --- | --- | --- |
{capabilities.map((c) => (
  `| ${c.id.displayName} | ${c.sourcePaths.join(", ")} | ${c.sourceLinks.map((l) => `[${l.text}](${l.url})`).join(", ")} |\n`
))}

## Versioning

Dokumentasi ini merepresentasikan versi current/latest Selesai. Situs ini dibangun pertama kali terhadap Selesai `0.5.22`.

Untuk referensi upstream Pi, kami menautkan ke [repositori Pi](https://github.com/earendil-works/pi) hanya saat perbandingan secara eksplisit membutuhkannya. Kami tidak menyatakan bahwa Pi tidak memiliki kemampuan tertentu kecuali klaim tersebut didukung bukti yang tersedia.
