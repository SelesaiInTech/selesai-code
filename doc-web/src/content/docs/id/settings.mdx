Selesai menyimpan pengaturan sebagai JSON di dua file: `~/.selesai/agent/settings.json` (global, berlaku untuk semua proyek) dan `.selesai/settings.json` (proyek, menimpa global untuk direktori saat ini). Edit file secara langsung, atau jalankan `/settings` di dalam sesi untuk mengubah opsi umum secara interaktif.

Halaman ini mencakup pengaturan yang paling sering disentuh orang. Referensi lengkap ada di [docs/settings.md](https://github.com/SelesaiInTech/selesai-code/blob/main/docs/settings.md) di GitHub, dan opsi per ekstensi ada di halaman [Kustomisasi](../customization/).

## Model

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `defaultProvider` | string | — | Provider default, mis. `"anthropic"` atau `"openai"`. |
| `defaultModel` | string | — | ID model default untuk sesi baru. |
| `defaultThinkingLevel` | string | — | Seberapa banyak agent berpikir sebelum menjawab: `"off"`, `"minimal"`, `"low"`, `"medium"`, `"high"`, atau `"xhigh"`. |
| `enabledModels` | string[] | — | Pola model untuk perpindahan Ctrl+P, mis. `["claude-*"]`. |

## Perutean model otomatis

Ekstensi bundel `auto-model` mengklasifikasikan setiap prompt idle top-level sebagai `simple`, `medium`, `complex`, atau `reasoning` dengan model keputusan Jev, lalu beralih ke model yang Anda konfigurasi untuk tier tersebut. Fitur ini tetap nonaktif sampai `autoModel.enabled` bernilai `true`.

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `autoModel.enabled` | boolean | `false` | Mengaktifkan perutean otomatis per prompt. |
| `autoModel.classifier.provider` | string | `"tokenin"` | Provider yang melayani deployment keputusan Jev. |
| `autoModel.classifier.model` | string | `"jev-1.13"` | Model keputusan yang dipanggil classifier. |
| `autoModel.classifier.baseUrl` | string | diwarisi | Override base URL; default-nya model terdaftar mana pun dari `classifier.provider`. |
| `autoModel.classifier.timeoutMs` | number | `10000` | Timeout permintaan classifier dalam milidetik. |
| `autoModel.classifier.minConfidence` | number | `0.5` | Di bawah keyakinan Jev ini, tier fallback dipakai. |
| `autoModel.classifier.contextTurns` | number | `4` | Giliran user sebelumnya yang dikirim sebagai konteks classifier. |
| `autoModel.classifier.contextChars` | number | `4000` | Batas karakter untuk konteks tersebut. |
| `autoModel.tiers.simple` | string | `"tokenin/deepseek-v4.1-flash"` | Model untuk sapaan, pencarian, dan transformasi kecil. |
| `autoModel.tiers.medium` | string | `"tokenin/celestial-pro"` | Model untuk coding rutin dan penjelasan (fallback default). |
| `autoModel.tiers.complex` | string | `"tokenin/celestial-max"` | Model untuk engineering non-trivial dan debugging akar masalah. |
| `autoModel.tiers.reasoning` | string | `"tokenin/celestial-ultra"` | Model untuk penalaran terbuka dan tradeoff. |
| `autoModel.fallbackTier` | string | `"medium"` | Tier yang dipakai saat classifier tidak tersedia. |

Setiap nilai tier adalah `provider/modelId`, dengan akhiran `:thinkingLevel` opsional (misalnya `tokenin/celestial-max:max`). Hanya prompt top-level idle yang dirutekan: pesan steering dan follow-up yang diantre, pesan dari ekstensi, dan perintah `/` tidak disentuh, karena model sesi bersifat global. Memilih model dengan `/model` menangguhkan perutean sampai akhir sesi. Timeout classifier, error, jawaban rusak atau ragu, model hilang atau di luar scope, atau kredensial tidak tersedia akan mempertahankan model saat ini atau beralih ke `fallbackTier`.

```json
{
  "autoModel": {
    "enabled": true,
    "classifier": { "provider": "tokenin", "model": "jev-1.13" },
    "tiers": {
      "simple": "tokenin/deepseek-v4.1-flash",
      "medium": "tokenin/celestial-pro",
      "complex": "tokenin/celestial-max",
      "reasoning": "tokenin/celestial-ultra"
    }
  }
}
```

## Tool

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `defaultTools` | string[] | — | Pemilihan tool bawaan awal untuk sesi baru. Saat disetel, sesi baru hanya mengaktifkan tool ini (berguna bersama SDK); saat dihilangkan, `read`, `bash`, `edit`, `write` default dipakai. |

## Tampilan

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `theme` | string | `"dark"` | `"dark"`, `"light"`, atau nama tema kustom. Anda juga bisa mengatur tema awal untuk satu sesi dengan `--use-theme <nama>`. |
| `quietStartup` | boolean | `false` | Sembunyikan bantuan keybinding dan daftar resource yang dimuat agar peluncuran lebih tenang. Banner brand selalu tampil dan menghilang pada pesan pertama Anda. |
| `tuiMode` | string | `"fullscreen"` | `"fullscreen"` (tata letak dock default) atau `"regular"` (tata letak Pi klasik). |
| `fullscreenExitOutput` | string | `"transcript"` | Yang terjadi saat keluar dari fullscreen: mencetak transkrip (`"transcript"`) atau hanya petunjuk resume sesi (`"resume-hint"`). |
| `fullscreenCopyOnSelect` | boolean | `true` | Menyalin teks terpilih secara otomatis di mode fullscreen; nonaktifkan untuk menyalin seleksi dengan Ctrl+X. |

## Konteks

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `compaction.enabled` | boolean | `true` | Kompakkan otomatis konteks lama saat percakapan membesar. |
| `compaction.reserveTokens` | number | `16384` | Token yang disisakan untuk balasan model. |
| `compaction.keepRecentTokens` | number | `20000` | Token terbaru yang tidak pernah diringkas. |

## Kepercayaan dan keamanan

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `defaultProjectTrust` | string | `"ask"` | Fallback untuk mempercayai proyek pada run non-interaktif: `"ask"`, `"always"`, atau `"never"`. Hanya pengaturan global. |

## Ekstensibilitas

| Pengaturan | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `packages` | array | `[]` | Package npm/git yang memuat ekstensi, skill, prompt, dan tema. |
| `extensions` | string[] | `[]` | File atau direktori ekstensi lokal yang dimuat. |
| `skills` | string[] | `[]` | File atau direktori skill tambahan, atau pola eksplisit `+`/`-`. Penemuan normal otomatis memuat skill dari `~/.selesai/agent/skills/`, `~/.agents/skills/`, `.selesai/skills/`, dan direktori `.agents/skills/` project/ancestor, sehingga pengaturan ini tidak wajib untuk skill biasa. |

## Tempat pengaturan berada

| Lokasi | Cakupan |
| --- | --- |
| `~/.selesai/agent/settings.json` | Global — berlaku untuk semua proyek. |
| `.selesai/settings.json` | Proyek — menimpa nilai global untuk direktori saat ini. |

Objek bersarang digabungkan, sehingga file proyek hanya perlu menimpa kunci yang diinginkan.

## Reset pabrik

Untuk mengembalikan pengaturan global ke default pabrik bawaan, jalankan `/settings-factory-reset` di dalam sesi. Perintah ini memberi peringatan sebelum mengganti `~/.selesai/agent/settings.json`, menyimpan cadangan `.bak` di samping file, dan tidak menyentuh kredensial (`auth.json`), sesi, ekstensi, skill, maupun tema.

## Satu contoh gabungan

```json
{
  "defaultProvider": "anthropic",
  "defaultModel": "claude-sonnet-4-20250514",
  "defaultThinkingLevel": "medium",
  "theme": "dark",
  "quietStartup": false,
  "tuiMode": "fullscreen",
  "fullscreenExitOutput": "transcript",
  "fullscreenCopyOnSelect": true,
  "defaultTools": ["read", "bash", "edit", "write"],
  "compaction": {
    "enabled": true,
    "reserveTokens": 16384,
    "keepRecentTokens": 20000
  },
  "defaultProjectTrust": "ask",
  "packages": ["pi-skills"]
}
```

Untuk daftar lengkap semua pengaturan, lihat [docs/settings.md](https://github.com/SelesaiInTech/selesai-code/blob/main/docs/settings.md). Untuk konfigurasi tingkat ekstensi, lihat halaman [Kustomisasi](../customization/).
