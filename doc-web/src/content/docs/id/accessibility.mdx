Selesai Docs dirancang untuk ringan, menghargai privasi, dan aksesibel.

## Aksesibilitas

- Dibangun di atas Starlight yang menyediakan HTML semantik, navigasi keyboard, dan tata letak responsif.
- Komponen kustom menggunakan indikator fokus yang terlihat, `aria-label`, dan region `aria-live` untuk tombol salin.
- Kontras warna dijaga pada tema gelap dan terang.
- Menghormati `prefers-reduced-motion` dengan menonaktifkan smooth scrolling dan transisi.
- Navigasi, pencarian, pengalih bahasa, dan tombol salin dapat digunakan dengan keyboard.

Jika Anda menemukan masalah aksesibilitas, buka issue di [repositori Selesai](https://github.com/SelesaiInTech/selesai-code/issues) dengan label `docs-a11y`.

## Privasi

- Tidak ada analytics, tracking, atau cookie yang disertakan di situs dokumentasi ini.
- Pencarian didukung oleh Pagefind dan berjalan sepenuhnya di browser.
- Tautan source eksternal terbuka di tab baru dengan `rel="noopener noreferrer"`.
