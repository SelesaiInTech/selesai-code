# Checkpoint rewind

## Apa ini dan mengapa membantu

Extension `pi-rewind-hook` menyediakan checkpoint file yang tepat dan didukung git di `/fork`, `/tree`, sesi yang dilanjutkan, dan silsilah sesi. Anda dapat memulihkan state file sebelumnya tanpa perintah git manual.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai `src/extensions/pi-rewind-hook/`.

## Mulai cepat

Rewind dipicu melalui perintah slash Selesai:

```sh
/rewind <target>
```

## Konfigurasi

Tidak diperlukan konfigurasi terpisah. Extension ini hook ke event siklus hidup sesi dan merekam checkpoint secara otomatis.

## Batasan dan edge case

- Rewind bergantung pada ketersediaan git di direktori project.
- Rewind mencatat state file, bukan memori atau state dunia eksternal.
- Checkpoint mungkin terbatas oleh riwayat git yang tersedia jika commit dibuat di luar Selesai.
