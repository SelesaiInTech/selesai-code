Ekstensi `auto-session-name` memberi nama sesi pada setiap pesan user menggunakan model yang sedang dipilih. Ia hanya mengirim riwayat pesan user (tanpa hasil tool, balasan assistant, atau thinking), membatasi nama hingga lima kata, dan berjalan di latar belakang sehingga tidak pernah menunda pesan Anda.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis; tidak perlu diinstal terpisah.
- Menggunakan model yang sedang dipilih dan kredensial API yang ada; jika tidak ada kunci, penamaan dilewati.
- Berfungsi di sesi interaktif; sesi diberi nama saat pesan user tiba.

## Yang disiapkan

- Mendengarkan event `input` dan mengabaikan pesan bersumber ekstensi, slash command, dan teks kosong.
- Mengumpulkan prompt user saat ini plus hingga 20 pesan user sebelumnya (terbaru dulu, masing-masing 200 karakter) sebagai satu-satunya konteks.
- Meminta nama sesi 1–5 kata ke model dengan batas output 10 token, lalu menerapkannya via `setSessionName`.
- Menonaktifkan thinking secara eksplisit (`reasoning_effort: "none"`) agar model reasoning tidak menghabiskan anggaran penamaan untuk penalaran internal.
- Menjalankan panggilan penamaan di latar belakang (fire-and-forget); pesan user langsung terkirim.

## Yang dapat dikonfigurasi

Tidak ada pengaturan user. Panjang nama, batas konteks, dan anggaran token adalah konstanta di sumber ekstensi.

## Yang dapat dilakukan

- Menjaga nama sesi tetap mutakhir secara otomatis saat topik percakapan berubah.
- Melihat nama diperbarui tanpa menjalankan `/name` manual setelah setiap pesan.
- Mengirim pesan tanpa latensi tambahan dari panggilan penamaan.

## Perintah, tool, dan shortcut

- Tidak ada. Ekstensi sepenuhnya otomatis.
- Perintah manual yang setara tetap `/name`.

## Batasan dan keamanan

- Penamaan bersifat best-effort; panggilan yang gagal atau lambat tidak pernah memblokir atau merusak alur pesan.
- Hanya panggilan penamaan dari pesan terbaru yang boleh menetapkan nama; respons lama yang lebih lambat dibuang.
- Permintaan penamaan hanya berisi teks pesan user. Tidak ada hasil tool, balasan assistant, atau konten thinking yang dikirim.
