Extension `copy-turn` memungkinkan Anda menyalin hasil user atau assistant dari branch sesi saat ini menggunakan hash singkat. Berguna untuk menggunakan kembali jawaban sebelumnya, output command, atau pesan assistant tanpa mengetik ulang.

## Penyiapan dan prasyarat

- Extension ini dibundel bersama Selesai. Dimuat otomatis; tidak perlu diinstal terpisah.
- Memerlukan sesi Selesai interaktif dengan TUI.
- Hanya berfungsi pada pesan di branch sesi saat ini. Pesan dicocokkan dengan hash SHA-1 dari konten yang dibersihkan.

## Yang disiapkan

- Mendaftarkan message renderer `copy-turn` kustom yang menambahkan marker salin di bawah pesan user dan menambahkan marker pada pesan assistant final setiap turn.
- Memelihara set hash per branch dengan membaca `ctx.sessionManager.getBranch()`.
- Menggunakan `copyToClipboard` dari runtime Selesai untuk menyalin konten yang cocok ke clipboard sistem.

## Yang dapat dilakukan

- Menyalin hasil pesan user atau assistant ke clipboard dengan mengetik hash-nya.
- Menggunakan prefix singkat selama tidak ambigu. Jika beberapa pesan cocok, Selesai memberitahu hash lengkap agar Anda dapat membedakan.

## Perintah, tool, dan shortcut

| Perintah | Deskripsi |
| --- | --- |
| `/cp <hash>` | Menyalin hasil pesan yang cocok ke clipboard. |

Pesan yang cocok difilter ke branch saat ini, tidak termasuk baris `copy-turn` kustom. Untuk pesan `bashExecution`, teks yang disalin adalah command ditambah output-nya; untuk role lain adalah konten teks dengan marker yang disingkirkan.

## Batasan dan keamanan

- `/cp` hanya berfungsi pada pesan yang masih ada di branch saat ini. Navigasi ke branch sesi yang berbeda mengubah hash yang tersedia.
- Hash adalah content hash, sehingga mengedit pesan setelah dirender menghasilkan hash yang berbeda.
- Hasil kosong dan prefix ambigu ditolak dengan peringatan.
- Extension menghapus marker salin dari konteks model, sehingga tidak mengembang konteks dengan marker berulang.
