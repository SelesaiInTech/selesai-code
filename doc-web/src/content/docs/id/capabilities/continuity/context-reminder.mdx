## Apa ini dan mengapa membantu

Extension `context-compaction-reminder` memperingatkan Anda saat percakapan menjadi besar dan menyarankan `/handoff-new` sebelum kualitas menurun atau biaya meningkat lebih lanjut.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai `src/extensions/context-compaction-reminder.ts`.

## Mulai cepat

Saat reminder muncul, gunakan sebagai sinyal untuk mereset konteks:

```sh
/handoff-new
```

## Konfigurasi

Tidak diperlukan konfigurasi terpisah. Reminder dipicu berdasarkan heuristik ukuran sesi.

## Batasan dan edge case

- Reminder bersifat advisory; Anda memilih apakah akan melakukan handoff.
- Jika diabaikan, biaya token dapat meningkat dan kualitas respons dapat menurun.
