Extension `question` menyediakan wizard terminal untuk mengajukan satu atau lebih pertanyaan bertipe ke user. Mendukung single-select, multiselect, free-form text, dan pertanyaan konteks/info, dengan navigasi keyboard dan filtering.

## Penyiapan dan prasyarat

- Extension ini dibundel bersama Selesai. Dimuat otomatis; tidak perlu diinstal terpisah.
- Memerlukan mode terminal TUI. Tidak dapat digunakan di sesi headless atau non-interaktif.
- Agent memanggil tool; user menjawab melalui TUI.

## Yang disiapkan

- Mendaftarkan tool `question` dan merender komponen batch question full-screen.
- Setiap pertanyaan memiliki `id` yang stabil, `label`, string `question`, `type`, dan `options` serta `context` opsional.
- Jawaban dikembalikan sebagai hasil terstruktur dengan status `answered`, `skipped`, dan `unanswered`.

## Yang dapat dikonfigurasi

- Tidak ada konfigurasi yang tampak untuk user. Skema pertanyaan fixed oleh definisi tool.

## Yang dapat dilakukan

- Mengajukan keputusan independen yang harus dibuat user secara langsung.
- Menampilkan pertanyaan select, multiselect, text, atau info-only.
- Menyediakan `value` opsi yang stabil terpisah dari `label` yang human-readable.

## Perintah, tool, dan shortcut

Tidak ada slash command. Tool dipanggil oleh agent:

```json
question({
  questions: [
    {
      id: "target_db",
      label: "Database",
      type: "select",
      question: "Which database should we use?",
      options: [
        { value: "sqlite", label: "SQLite" },
        { value: "postgres", label: "PostgreSQL" }
      ],
      allowOther: true
    },
    {
      id: "skip_cache",
      label: "Skip cache",
      type: "text",
      question: "Why skip the cache?"
    }
  ]
})
```

Tipe pertanyaan yang didukung: `select`, `multiselect`, `text`, `image`, `info`.

Saat meninjau, user dapat berpindah antar pertanyaan dengan `Tab`/`Shift+Tab`, membiarkan pertanyaan text kosong untuk melewatkannya, dan menekan `Enter` di layar review untuk mengirim jawaban akhir.

## Batasan dan keamanan

- Tool hanya berfungsi di mode TUI. Memanggilnya dari sesi non-interaktif menghasilkan error.
- Pertanyaan seharusnya adalah keputusan independen yang harus dibuat user; agent harus memeriksa fakta sendiri daripada menanyakan informasi yang dapat ditemukan kepada user.
- Pertanyaan `info` hanya berisi konteks dan tidak memerlukan respons.
- Entri text kosong dicatat sebagai `skipped`; agent harus menangani status skipped dan unanswered secara eksplisit.
