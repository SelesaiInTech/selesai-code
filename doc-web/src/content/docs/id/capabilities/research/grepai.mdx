## Penyiapan dan prasyarat

- grepai disediakan dari rilis GitHub resmi `yoanbernabeu/grepai` ke direktori biner terkelola Selesai jika tidak ada biner sistem yang terverifikasi.
- Kredensial Token-In harus sudah dikonfigurasi (`/tokenin add`).
- grepai menyimpan konfigurasi proyek di `.grepai/config.yaml`; integrasi membuatnya secara lazy saat command grepai yang membutuhkan konfigurasi dipakai pertama kali, atau langsung dengan `/setup-grepai`.
- Integrasi memaksa `store.backend: gob`, sehingga index tetap berbasis file di `.grepai/` dan tidak membutuhkan database eksternal.
- Saat proyek yang sudah dikonfigurasi dimulai, Selesai menjalankan `grepai watch --background`; grepai melakukan scan awal dan menjaga index tetap diperbarui saat file berubah.
- Setel `PI_OFFLINE=1` untuk mencegah pengunduhan biner terkelola.

## Yang disiapkan

- Mengunduh dan memverifikasi checksum rilis grepai terbaru sesuai platform.
- Memakai provider OpenAI-kompatibel grepai dengan model `nomic-code`.
- Mengatur endpoint ke `https://lite.andlet.me/v1`; grepai menambahkan `/embeddings`, sehingga request dikirim ke `https://lite.andlet.me/v1/embeddings`.
- Memilih store GOB berbasis file grepai dengan `store.backend: gob`.
- Mengambil API key Token-In aktif dari auth storage Selesai dan menulisnya ke `.grepai/config.yaml` dengan mode `0600`; key tidak pernah dicatat atau diberikan melalui argv.
- Mempertahankan pengaturan grepai proyek lain yang tidak terkait.
- Menjalankan watcher background setelah `/setup-grepai` dan pada startup Selesai berikutnya untuk proyek yang sudah dikonfigurasi.

## Yang dapat dikonfigurasi

<ExtensionCustomization slug="grepai" locale="id" />

Integrasi memakai 768 dimensi untuk `nomic-code`, berdasarkan lebar embedding kode Nomic yang diharapkan. Store GOB default berbasis file dan tidak membutuhkan dimensi koleksi database; verifikasi metadata proxy sebelum beralih manual ke Postgres atau Qdrant.

## Yang dapat dilakukan

- Jalankan `/setup-grepai` untuk menginstal grepai, mengonfigurasi proyek saat ini, dan memulai indexing.
- Minta agent menjalankan `grepai search "authentication flow"`; watcher dimulai otomatis sebelum search pertama jika diperlukan.
- Gunakan `grepai watch --status` atau `grepai watch --stop` untuk memeriksa atau menghentikan watcher otomatis.
- Gunakan `GREPAI_DISABLED=1` untuk menonaktifkan provisioning dan setup otomatis.
- Gunakan `SELESAI_SKIP_GREPAI_SETUP=1` untuk tetap mengizinkan provisioning tetapi melewati konfigurasi proyek otomatis.

## Perintah, tool, dan shortcut

| Perintah | Deskripsi |
| --- | --- |
| `/setup-grepai` | Instal grepai dan konfigurasi proyek saat ini dari kredensial Token-In aktif. |
| `grepai init` | Command inisialisasi upstream; setup Selesai memakainya dengan provider OpenAI dan `nomic-code`. |
| `grepai watch` | Jalankan watcher index foreground atau background secara manual; proyek terkonfigurasi menjalankannya otomatis. |
| `grepai watch --status` | Periksa status watcher otomatis. |
| `grepai watch --stop` | Hentikan watcher otomatis. |
| `grepai search <query>` | Cari proyek terindeks secara semantik. |
| `grepai trace ...` | Lacak relasi symbol/call jika didukung versi grepai terpasang. |

## Batasan dan keamanan

- Konfigurasi grepai bersifat tingkat proyek, bukan registrasi model-provider Selesai; proses Go grepai sendiri yang mengirim request embedding.
- Key Token-In disimpan di `.grepai/config.yaml` karena grepai upstream hanya mendukung `embedder.api_key` literal atau fallback `OPENAI_API_KEY` tingkat proses. Pastikan `.grepai/` di-ignore dan periksa permission file.
- Integrasi fail-open: jika instalasi atau setup gagal, command Bash asli tetap boleh berjalan.
- Alias `nomic-code` dan dimensinya berasal dari proxy LiteLLM, bukan repository grepai; perubahan model di proxy mungkin memerlukan pembaruan konfigurasi proyek.
