## Apa ini dan mengapa membantu

`pi-web-agent` yang dibundel menyediakan satu tool `web_explore` untuk riset yang membutuhkan sumber terkini. Tool ini melakukan pencarian dan fetch terbatas, merangking sumber, mengekstrak konten yang *readable*, dan menaikkan ke headless browser bila diperlukan.

## Ketersediaan

Termasuk dalam `@selesai/code`. DuckDuckGo adalah jalur pencarian default. Onboarding pertama kali opsional dapat mengkonfigurasi Brave Search dengan fallback DuckDuckGo.

## Mulai cepat

```text
Search the web for the latest React Server Components best practices and compare them with this codebase.
```

## Konfigurasi

Gunakan `/web-agent` untuk mengakses pengaturan backend dan presentasi serta diagnostics.

Untuk mengaktifkan Brave Search:

1. Kunjungi [halaman Brave Search API](https://brave.com/search/api/).
2. Buat key di [dashboard Brave API](https://api-dashboard.search.brave.com/app/keys).
3. Jalankan alur onboarding web-agent.

```sh
/web-agent
```

## Batasan dan edge case

- `web_explore` untuk dokumentasi terkini, diskusi teknis, perbandingan, dan rekomendasi.
- Ini bukan lisensi untuk diam-diam melakukan network call sembarangan dari shell command.
- Beberapa host memblokir fetch otomatis; orchestrator dapat menaikkan ke headless browser bila source mendukung.
