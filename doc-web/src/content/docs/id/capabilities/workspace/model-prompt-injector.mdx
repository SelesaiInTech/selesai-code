model-prompt-injector adalah ekstensi bawaan yang menyuntikkan prompt khusus model ke system prompt setiap kali model aktif cocok dengan sebuah aturan. Aturan berada di file konfigurasi di samping ekstensi; tidak ada yang diekspos ke pengaturan user, dan `/reload` membaca ulang konfigurasi.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis.
- Konfigurasi berada di `src/extensions/model-prompt-injector/config.json` di codebase host; tidak ada permukaan pengaturan tingkat user.
- `/reload` membaca ulang file konfigurasi setelah diedit.

## Yang disiapkan

- Membaca array `rules`, masing-masing dengan daftar glob `match`, `mode` (`prepend`, `append`, atau `replace`), `prompt`, dan flag `enabled`.
- Saat model aktif cocok dengan aturan, prompt disuntikkan ke system prompt pada posisi yang dikonfigurasi.
- Pencocok mendukung pasangan provider/model, wildcard provider, referensi model apa pun, nama telanjang, dan `*`.

## Yang dapat dikonfigurasi

Aturan diedit di `config.json` di samping source ekstensi; tidak ada pengaturan yang menghadap user, variabel lingkungan, atau slash command untuk ekstensi ini.

## Yang dapat dilakukan

- Menambahkan (prepend), melampirkan (append), atau mengganti konten system prompt per keluarga model.
- Mencocokkan model tertentu atau seluruh keluarga provider dengan pola glob.
- Menonaktifkan aturan tanpa menghapusnya.

## Perintah, tool, dan shortcut

- `/reload` — membaca ulang konfigurasi ekstensi setelah mengedit `config.json`.

## Batasan dan keamanan

- Perubahan konfigurasi memerlukan reload agar berlaku.
- Aturan `replace` menimpa bagian prompt yang relevan; gunakan secara hati-hati.
- Ekstensi ini hanya mengubah system prompt untuk model yang cocok; tidak mengubah routing atau pemilihan model.
