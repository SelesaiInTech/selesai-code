Selesai mula-mula hanya mengekspos permukaan tool bootstrap (`read`, `bash`, `edit`, `write`), lalu mendaftarkan tool read-only standar (`grep`, `find`, `ls`) setelah pemanggilan tool durable pertama yang berhasil.

## Penyiapan dan prasyarat

Perilaku ini dibundel dan otomatis. Tidak perlu setup atau konfigurasi.

## Yang disiapkan

- Mendaftarkan `grep`, `find`, dan `ls` setelah pemanggilan tool bootstrap pertama yang berhasil.
- Menjaga permukaan bootstrap tetap stabil sampai pemanggilan pertama itu berhasil.

## Yang dapat dikonfigurasi

Tidak ada pengaturan yang ditujukan untuk user. Visibilitas tool didefinisikan oleh source.

## Yang dapat dilakukan

Gunakan tool read-only normal setelah pemanggilan bootstrap tanpa perlu mengaktifkan extension secara manual.

## Perintah, tool, dan shortcut

Tidak ada command atau shortcut untuk extension bootstrap internal ini.

## Batasan dan keamanan

Pemanggilan tool durable pertama harus selesai sebelum katalog read-only didaftarkan. Pemanggilan tool yang gagal tidak memicu pendaftaran.
