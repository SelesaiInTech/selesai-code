Selesai menyertakan provider Ollama yang kompatibel dengan OpenAI untuk model lokal.

## Penyiapan dan prasyarat

- Pasang dan jalankan Ollama secara lokal.
- Provider ini dikirim otomatis bersama `@selesai/code`.

## Yang disiapkan

- Mendaftarkan provider Ollama lokal bawaan dan integrasinya dengan katalog model.

## Yang dapat dikonfigurasi

<ExtensionCustomization slug="custom-provider-ollama" locale="id" />

## Yang dapat dilakukan

- Memilih model Ollama lokal melalui pemilih model dan alur refresh katalog standar.

## Perintah, tool, dan shortcut

Gunakan pemilih model standar dan `/settings`; extension ini tidak menambahkan slash command khusus.

## Batasan dan keamanan

Perilaku model lokal, ketersediaan, dan kebutuhan hardware ditentukan oleh Ollama serta model yang dipilih.
