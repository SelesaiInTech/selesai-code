Extension `web-agent-onboarding` berjalan pada startup Selesai interaktif pertama dan menawarkan untuk mengkonfigurasi Brave Search untuk `pi-web-agent` yang dibundel. Jika Anda menolak, agent menggunakan backend DuckDuckGo default.

## Penyiapan dan prasyarat

- Extension ini dibundel bersama Selesai. Dimuat otomatis; tidak perlu diinstal terpisah.
- Hanya berjalan saat startup pertama (`event.reason === "startup"`) sampai marker onboarding ditulis.
- Memerlukan sesi TUI interaktif untuk menampilkan konfirmasi dan prompt paste.
- Akses jaringan ke `https://api-dashboard.search.brave.com/app/keys` diperlukan jika Anda memilih membuka dashboard Brave.

## Yang disiapkan

- Menulis `~/.selesai/agent/.webAgentOnboardingComplete` setelah onboarding selesai atau dilewati secara eksplisit.
- Jika Anda setuju, menyimpan `webAgent.braveApiKey` di `~/.selesai/agent/settings.json`.
- Menulis config backend global yang memilih Brave dengan fallback DuckDuckGo di `~/.selesai/agent/extensions/pi-web-agent/config.json`.
- Memicu reload extension sehingga backend `pi-web-agent` membaca ulang config baru.

## Yang dapat dilakukan

- Menerima prompt pertama kali untuk menggunakan Brave Search. Ia membuka dashboard Brave API key, memungkinkan Anda menempel key, dan mengalihkan `pi-web-agent` ke Brave secara otomatis.
- Menolak prompt untuk mempertahankan backend DuckDuckGo.
- Menjalankan `/setup-web-search` kapan saja untuk menjalankan ulang alur.

## Perintah, tool, dan shortcut

| Perintah | Deskripsi |
| --- | --- |
| `/setup-web-search` | Jalankan ulang alur Brave Search onboarding, lalu reload extension jika key tersimpan. |

## Batasan dan keamanan

- Marker onboarding mencegah prompt muncul lagi meskipun Anda melewati atau membatalkan. Gunakan `/setup-web-search` untuk menjalankan ulang.
- Brave key disimpan di `~/.selesai/agent/settings.json`. Jangan commit file tersebut atau membagikan key.
- Jika Brave tidak tersedia di wilayah Anda atau key tidak valid, `pi-web-agent` masih dapat fallback ke DuckDuckGo ketika `fallback: "duckduckgo"` dikonfigurasi.
