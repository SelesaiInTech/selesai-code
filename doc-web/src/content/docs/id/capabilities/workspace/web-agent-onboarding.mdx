## Apa ini dan mengapa membantu

Extension `web-agent-onboarding` menyediakan jalur konfigurasi pertama kali untuk web agent yang dibundel, secara opsional mengaktifkan Brave Search dengan fallback DuckDuckGo.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai `src/extensions/web-agent-onboarding.ts`.

## Mulai cepat

Saat pertama kali berjalan, Selesai mungkin meminta Anda mengkonfigurasi pencarian web. Untuk menjalankan ulang onboarding:

```sh
/web-agent-onboard
```

## Konfigurasi

1. Kunjungi halaman Brave Search API untuk meminta akses.
2. Buat API key di dashboard Brave API.
3. Tempelkan key saat diminta selama onboarding.

DuckDuckGo tetap menjadi fallback jika Brave tidak dikonfigurasi.

## Batasan dan edge case

- Brave Search memerlukan API key dan mungkin memiliki batas penggunaan.
- Fallback DuckDuckGo tidak memerlukan key tetapi dapat membatasi penggunaan intensif.
- Akses jaringan diperlukan untuk kedua backend pencarian.
