Graft memberi Selesai graph semantik lokal dari Git working tree saat ini. Selesai membangun graph itu untuk repository aktif saat pertama dipakai—deep bila model aktif kompatibel, jika tidak tetap lokal dan struktural—dan turn coding yang memenuhi syarat secara default menerima context berbasis source yang dibatasi, sementara tool read-only presisi tetap tersedia untuk tindak lanjut.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis di Git working tree.
- CLI `@nanonets/graft` yang kompatibel (`>=0.18.0 <1.0.0`) dipasang otomatis saat belum ada; instalasi user yang tidak kompatibel tidak pernah ditimpa.
- Graph pertama dibuat otomatis: awal sesi, panggilan tool Graft pertama, dan instalasi CLI yang selesai masing-masing membangun repository satu kali.
- Build otomatis itu bersifat deep bila model aktif kompatibel (TokenIn, LiteLLM, OpenAI, Anthropic, atau OrcaRouter), dan lokal serta struktural bila tidak.
- `/graft build` dan `/graft setup` membangun sesuai permintaan. Build deep meminta konfirmasi karena mengirim ringkasan turunan source melalui model Selesai aktif; `/graft build --structural` tetap offline tanpa model dan tanpa API key.

## Yang disiapkan

- Menjaga graph `graft/` yang dapat dibuat ulang di luar Git dan memasukkannya kembali hanya untuk pencarian lokal.
- Menetapkan default `DO_NOT_TRACK=1` untuk proses child Graft tanpa mengubah konfigurasi Graft sendiri.
- Menyuntikkan satu paket orientasi yang dibatasi sebelum turn coding yang memenuhi syarat dalam mode `hybrid`, mode default; `push` memakai lebih banyak byte untuk paket berbasis source, dan `pull` menyerahkan retrieval ke tool.
- Meneruskan kredensial model aktif hanya ke proses child Graft untuk build tersebut, dan tidak pernah mengaturnya di environment host.
- Menandai graph berubah setelah edit Selesai dan me-refresh graph yang sudah ada pada batas idle berikutnya.
- Menambahkan enam tool read-only Graft ke builtin subagent `scout`, `reviewer`, `worker`, `delegate`, dan `oracle`. Override tool atau child-extension eksplisit dari user tetap diprioritaskan.

## Yang dapat dilakukan

- Jalankan `/graft setup` untuk alur instal-dan-build terpandu, atau `/graft doctor` untuk memeriksa repository, CLI, graph, mode, telemetri, dan kesiapan provider.
- Andalkan build pertama otomatis, atau jalankan sendiri `/graft build` (deep) atau `/graft build --structural` (offline).
- Ganti retrieval dengan `/graft mode pull`, `/graft mode push`, atau `/graft mode hybrid`.
- Gunakan `graft_find_code` untuk menemukan kode relevan, lalu verifikasi file yang dirujuk sebelum mengedit.
- Gunakan `graft_trace_calls` sebelum mengubah perilaku bersama, dan `graft_check_freshness` ketika context Graft sebelumnya mungkin mendahului edit.

## Perintah, tool, dan shortcut

| Permukaan | Deskripsi |
| --- | --- |
| `/graft status` / `/graft doctor` | Tampilkan status ringkas atau laporan diagnostik lengkap. |
| `/graft setup` / `build` / `deep` / `refresh` | Instal jika diperlukan, lalu build (deep secara default) atau re-index. |
| `/graft build --structural` | Build lokal tanpa model dan tanpa API key. |
| `/graft mode [pull\|push\|hybrid]` | Tampilkan atau atur strategi retrieval untuk branch sesi ini. |
| `graft_find_code({ question, limit?, in? })` | Retrieval kode berbasis source dengan peringkat. |
| `graft_file_api({ path })` | Signature tanpa body implementasi. |
| `graft_trace_calls({ symbol, direction?, depth? })` | Caller/dependent atau dependensi keluar. |
| `graft_find_all({ pattern, ignore_case?, fixed?, in? })` | Pencarian regex terindeks menyeluruh yang dikelompokkan per simbol. |
| `graft_repo_map({ max_dirs? })` | Cluster direktori dan hotspot repository. |
| `graft_check_freshness()` | Laporkan drift graph tanpa rebuild. |

## Batasan dan keamanan

- Tool Graft bersifat read-only. Command build `/graft` memerlukan konfirmasi eksplisit; build otomatis pertama berjalan tanpa prompt karena model aktif yang kompatibel sudah menjadi pilihan provider sesi ini.
- Ekstensi tidak pernah menjalankan command `init` Graft dan tidak pernah menulis konfigurasi coding agent lain.
- Graph adalah context turunan, bukan source of truth: periksa file yang dirujuk sebelum mengubahnya.
- Graph struktural bersifat lokal dan offline. Build deep mengirim material turunan source hanya ke model Selesai aktif, dan kredensialnya diteruskan hanya ke proses child Graft tersebut.
- Atur `graft.enabled: false` di pengaturan untuk menyingkirkan build otomatis, refresh, dan tool dari sesi sepenuhnya.
