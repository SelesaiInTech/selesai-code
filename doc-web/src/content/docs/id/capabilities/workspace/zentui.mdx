Zentui adalah statusline terinspirasi Starship dan TUI bergaya Opencode untuk Selesai. Memberikan lima permukaan kepemilikan dan styling independen — editor, pesan user, thinking (eksperimental), working line, dan footer — dengan statusline opsional bergaya Starship.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis; tidak diperlukan instalasi terpisah.
- Memerlukan sesi TUI interaktif; tidak berpengaruh dalam mode headless.
- Permukaan editor, pesan user, thinking, working line, dan border selector masing-masing memiliki field `enabled` independen; footer menggunakan satu `style`: `native`, `starship`, atau `hidden`.

## Yang disiapkan

- **Editor** — perlakuan input Opencode, Opencode copy-friendly, Accent Rail, dan Minimalist.
- **Pesan user** — pesan transkrip framed, framed copy-friendly, compact, dan labeled.
- **Thinking (Eksperimental)** — renderer privat opsional Rail, Tree, atau Streaming untuk thinking Pi, tanpa mengambil alih Working line.
- **Working line** — pengambilalihan opsional atas baris sedang berjalan lengkap Pi dan ringkasan turn yang selesai.
- **Footer** — footer native Pi, statusline bergaya Starship, atau footer nol-baris tersembunyi, dengan segmen yang dapat dikonfigurasi dan template format footer compact.
- Mendaftarkan perintah `/zentui` untuk konfigurasi langsung dan toggle cepat.

## Yang dapat dikonfigurasi

<ExtensionCustomization slug="zentui" locale="id" />

Jalankan `/zentui` untuk mengonfigurasi Appearance, Editor, User messages, Thinking (Eksperimental), Working line, Footer, Segments, Git, dan Extensions. Gunakan `Tab` dan `Shift+Tab` untuk berpindah bagian; perubahan diterapkan langsung dan disimpan ke `~/.selesai/agent/zentui.json`.

## Yang dapat dilakukan

- Toggle permukaan satu per satu: `/zentui editor toggle`, `/zentui messages toggle`, `/zentui statusline toggle`, `/zentui viewport-indicators toggle`.
- Konfigurasikan pengambilalihan working line dengan `/zentui working-line`.
- Atur template format footer compact: `/zentui format "$cwd on branch $git_branch$git_status using $runtime $fill $context"`.
- Ganti gaya footer antara `native`, `starship`, dan `hidden` tanpa mengikatnya ke komponen lain.

## Perintah, tool, dan shortcut

- `/zentui` — buka picker konfigurasi langsung.
- `/zentui <permukaan> toggle` — balik satu permukaan tanpa membuka picker.
- `/zentui format <template>` — atur format footer compact.

## Batasan dan keamanan

- Hanya sesi TUI interaktif yang merender permukaan Zentui.
- Thinking (Eksperimental) nonaktif secara default dan dapat rusak setelah pembaruan Pi. Streaming aktif dapat beralih langsung ke Rail atau Tree, dan Rail serta Tree dapat saling beralih langsung; pengaktifan pertama, pengaktifan ulang setelah nonaktif langsung, dan masuk ke Streaming dari mode struktural memerlukan restart Pi. Kegagalan kembali ke thinking native penuh.

- Hanya sesi TUI interaktif yang merender permukaan Zentui.
- Tampilan path footer Starship default `basename`; pilih mode `repository` untuk menghilangkan direktori repository itu sendiri.
- Konfigurasi adalah satu file tingkat user; tidak ada lapisan proyek.
