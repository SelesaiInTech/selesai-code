Extension `pi-powerline-footer` menyesuaikan TUI fullscreen native Selesai dengan status bar bergaya powerline, tur panduan berulang, shortcut stash/riwayat editor, bash mode lengket, queue/inbox berbasis file, perpindahan direktori yang mengikuti sesi, vibe working bertema, dan deteksi Nerd Font.

## Penyiapan dan prasyarat

- Extension ini dibundel bersama Selesai. Dimuat otomatis; tidak perlu diinstal terpisah.
- Memerlukan sesi TUI interaktif. Tidak berpengaruh dalam mode headless.
- Nerd Font direkomendasikan untuk preset `nerd` tetapi tidak wajib; preset `ascii` aman untuk terminal apa pun.
- Sticky bash mode membutuhkan shell yang kompatibel POSIX.

## Yang disiapkan

- Mengganti footer/header/editor chrome default dengan segment bergaya powerline.
- Mendaftarkan command `/powerline`, `/guide`, `/stash-history`, `/bash-mode`, `/bash-reset`, `/vibe`, `/idea`, `/ideas`, `/queue`, dan `/cd`.
- Menambahkan queue dan inbox berbasis file agar Anda dapat menyimpan ide atau menahan prompt dengan aman selama compaction tanpa mengganggu agent saat ini.
- Mendaftarkan keyboard shortcut untuk editor stash, copy/cut, toggle bash-mode, dan riwayat stash.
- Status, editor, dan widget-nya dirender di dock fullscreen native Pi sementara transkrip dapat di-scroll secara independen.

## Yang dapat dilakukan

- Toggle powerline on/off: `/powerline`.
- Ganti preset: `/powerline nerd`.
- Fullscreen adalah default Selesai; atur `"tuiMode": "regular"` untuk memilih keluar.
- Scroll transkrip native dengan mouse wheel atau trackpad.
- Buka panduan berulang: `/guide` (default compact; gunakan `/guide full`, `/guide compact`, `/guide off`, atau `/guide reset`).
- Stash atau restore teks editor: `Alt+S`.
- Buka riwayat prompt: `Ctrl+Alt+H` atau `/stash-history`.
- Copy seluruh teks editor: `Ctrl+Alt+C`. Cut: `Ctrl+Alt+X`.
- Toggle sticky bash mode: `Ctrl+Shift+B` atau `/bash-mode on|off|toggle`.
- Reset shell yang dikelola: `/bash-reset`.
- Set tema working vibe: `/vibe star trek` atau `/vibe off`.
- Simpan ide untuk nanti: `# <idea>` atau `/idea <idea>`; telusuri atau kirim dengan `/ideas`.
- Periksa, coba ulang, ubah target, atau kirim prompt tertahan dengan `/queue`.
- Lanjutkan percakapan saat ini dari direktori lain dengan `/cd <path>`.
- Atur segmen, separator, penempatan, welcome screen, dan tampilan biaya melalui pengaturan `powerline`.

## Batasan dan keamanan

- UI powerline hanya dirender dalam sesi TUI interaktif.
- Sticky bash mode menyimpan shell yang dikelola untuk sesi Selesai saat ini. Shell `cd` dan variabel yang diekspor bertahan antar command, tetapi shell dan transkripnya hilang saat sesi berakhir.
- `# <idea>` hanya menangkap ide bila `#` diikuti spasi; atur `powerline.queue.captureSigil` ke `false` bila heading Markdown lebih sering digunakan, lalu gunakan `/idea`. Prompt yang ditahan selama compaction hanya dikirim setelah compaction berhasil; pekerjaan yang gagal atau dibatalkan tetap terlihat di queue.
- Pesan vibe yang dihasilkan menggunakan model yang dikonfigurasi dan di-rate-limit. Pre-generate file vibe dengan `/vibe generate <theme> <count>` untuk menghindari latency dan biaya API.
- Powerline tidak mengendalikan scrolling terminal; pilih `"tuiMode": "regular"` bila terminal Anda tidak kompatibel dengan mode fullscreen.
- Konflik shortcut custom dengan key yang dicadangkan secara otomatis diresolve ke default yang aman.
