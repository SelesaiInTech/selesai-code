Routing model otomatis adalah extension bawaan yang mengklasifikasikan setiap prompt user yang memenuhi syarat lalu memilih model yang dikonfigurasi untuk salah satu dari empat tier tingkat kesulitan. Fitur ini nonaktif secara default agar pemilihan model tidak berubah sebelum Anda memilih untuk mengaktifkannya.

## Penyiapan dan prasyarat

- Extension ini dikirim bersama Selesai dan dimuat otomatis; tidak perlu instalasi terpisah.
- Konfigurasikan setidaknya satu target `provider/model` yang tersedia untuk sebuah tier. Target dibatasi pada model yang terlihat dalam scope sesi saat ini.
- Aktifkan dengan `/auto-model-settings enable` setelah konfigurasi diperiksa.

## Yang disiapkan

- Classifier menetapkan prompt ke `simple`, `medium`, `complex`, atau `reasoning`.
- Extension beralih ke target tier yang dikonfigurasi sebelum prompt diproses, dan mempertahankan model saat ini bila target belum diatur atau tidak tersedia.
- Konfigurasi berlapis secara global di `~/.selesai/agent/extensions/auto-model/config.json` dan, untuk proyek tepercaya, di `.selesai/extensions/auto-model/config.json`; nilai proyek menimpa global.

## Yang dapat dikonfigurasi

Classifier default adalah LLM dengan timeout 3 detik dan tiga turn user sebelumnya (300 karakter per turn). Atur `classifier` ke `heuristic` untuk menghindari pemanggilan model classifier, atau konfigurasikan `provider/model` classifier yang tersedia.

## Yang dapat dilakukan

- Mengaktifkan atau menonaktifkan routing dan memeriksa pengaturan efektif.
- Menetapkan model berbeda untuk keempat tier, dengan scope global atau proyek tepercaya.
- Menguji klasifikasi tanpa mengganti model.

## Perintah, tool, dan shortcut

Gunakan slash command bawaan:

```text
/auto-model-settings show
/auto-model-settings enable
/auto-model-settings disable
/auto-model-settings set simple provider/model
/auto-model-settings classifier heuristic
/auto-model-settings test jelaskan perubahan ini
```

Di TUI, `/auto-model-settings` tanpa argumen membuka picker tier dan model. Tambahkan `--project` untuk menulis pengaturan proyek tepercaya; tanpa flag tersebut command menulis layer global. `/auto-model-settings set` hanya menerima model yang tersedia dalam scope.

## Batasan dan keamanan

- Routing nonaktif secara default.
- Routing berjalan untuk input interaktif atau RPC saat sesi idle; input dari extension, input queued/streaming, dan input saat agent sibuk tidak dirouting. Input diproses secara serial, sehingga routing prompt konkuren tidak dijamin independen.
- Pemilihan model manual menangguhkan routing sampai `/auto-model-settings enable` digunakan. Pemilihan model yang dipulihkan tidak membuat penangguhan baru.
- Classifier menerima prompt saat ini dan konteks user terbaru sampai batas yang dikonfigurasi. Kegagalan atau timeout classifier beralih ke klasifikasi heuristic lokal; tidak ada pergantian target bila tier terpilih tidak memiliki model yang tersedia.
