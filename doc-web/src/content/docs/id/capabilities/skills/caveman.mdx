Extension `caveman` menambahkan mode komunikasi singkat ke Selesai. Saat aktif, extension menambahkan instruksi caveman ke system prompt agen sehingga jawaban tetap singkat, fokus, dan bebas prosa yang tidak perlu.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis; tidak diperlukan instalasi terpisah.
- Skill pendamping berada di `src/skills/caveman/` dan dipanggil via `/skill:caveman` atau command `/caveman`.
- Memerlukan sesi TUI interaktif untuk indikator status bar dan notifikasi.

## Yang disiapkan

- Mendaftarkan slash command `/caveman` untuk toggle, enable, disable, dan cek status.
- Menambahkan entri custom session `caveman-mode` setiap kali mode berubah, sehingga state aktif bertahan antar turn dalam sesi yang sama.
- Menampilkan indikator status bar (`● 🦴 caveman: ON` atau `○ 🦴 caveman: OFF`) saat extension dimuat.
- Menyuntikkan instruksi caveman ke `before_agent_start` saat mode aktif.

## Yang dapat dikonfigurasi

Caveman tidak memiliki file konfigurasi sendiri. Perilaku dikontrol melalui slash command dan state sesi.

| Kontrol | Efek |
| --- | --- |
| `/caveman on` atau `/caveman enable` | Menyalakan caveman mode untuk sesi. |
| `/caveman off` atau `/caveman disable` | Mematikan caveman mode untuk sesi. |
| `/caveman status` | Menampilkan apakah caveman mode sedang on atau off. |
| `/caveman` | Toggle mode saat ini. |
| `stop caveman` atau `normal mode` | Frasa natural language yang mematikan caveman mode. |

Default fallback state jika tidak ada history sesi adalah **on** (`active = true`).

## Yang dapat dilakukan

- Beralih ke jawaban singkat dengan mengetik `/caveman on` atau memanggil `/skill:caveman`.
- Cek state saat ini dengan cepat menggunakan `/caveman status`.
- Kembali ke level detail normal dengan `/caveman off`, `stop caveman`, atau `normal mode`.
- Gunakan caveman saat Anda sudah memahami domain dan hanya butuh arahan ringkas, ringkasan diff, atau daftar command.

## Perintah, tool, dan shortcut

| Perintah | Deskripsi |
| --- | --- |
| `/caveman` | Toggle caveman mode. |
| `/caveman on` / `/caveman enable` | Mengaktifkan caveman mode. |
| `/caveman off` / `/caveman disable` | Mematikan caveman mode. |
| `/caveman status` | Menampilkan mode saat ini. |
| `/skill:caveman` | Memanggil skill pendamping secara langsung. |
| `stop caveman` atau `normal mode` | Mematikan via frasa natural language (harus seluruh pesan). |

Tidak ada tool atau keyboard shortcut yang terdaftar.

## Batasan dan keamanan

- Caveman mengurangi kedalaman penjelasan. Matikan saat Anda butuh reasoning detail, pengajaran, atau diskusi langkah demi langkah.
- Frasa deaktivasi (`stop caveman`, `normal mode`) hanya bekerja sebagai pesan user utuh; tidak terpicu di dalam prompt yang lebih besar.
- Status dilacak per session branch melalui entri `caveman-mode`. Sesi baru tanpa history fallback ke state default on.
- Extension hanya memodifikasi system prompt; tidak mengubah tool yang tersedia atau cara model dipanggil.
