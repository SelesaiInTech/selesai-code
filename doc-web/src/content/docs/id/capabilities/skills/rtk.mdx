## Apa ini dan mengapa membantu

Extension `rtk` menulis ulang shell command yang kompatibel untuk mengurangi output berisik dan penggunaan token saat `rtk` terpasang di sistem. Extension ini mengubah command seperti `ls` atau `cat` menjadi equivalent yang lebih diam di balik layar.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai `src/extensions/rtk.ts`. Memerlukan binary `rtk` yang terpisah untuk diinstal.

## Mulai cepat

Pasang `rtk` di sistem Anda, lalu jalankan Selesai seperti biasa. Command yang kompatibel akan ditulis ulang secara otomatis.

```sh
# Contoh command yang mungkin ditulis ulang jika rtk tersedia
selesai -p "list the files in the current directory"
```

## Konfigurasi

Tidak diperlukan konfigurasi khusus Selesai. Extension mendeteksi ketersediaan `rtk` saat runtime.

## Batasan dan edge case

- Hanya command yang kompatibel yang ditulis ulang. Command yang tidak dipahami `rtk` dibiarkan apa adanya.
- Jika `rtk` tidak terpasang, Selesai menjalankan command apa adanya.
- Output yang ditulis ulang mungkin sedikit berbeda dari command asli; tinjau jika output tepat diperlukan.
