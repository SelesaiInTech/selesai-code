Extension `rtk` menulis ulang tool call Bash yang kompatibel untuk menggunakan binary `rtk` eksternal. Ini mengurangi output command yang berisik dan menghemat token saat `rtk` terpasang, tanpa mengubah perilaku rewrite Selesai sendiri.

## Penyiapan dan prasyarat

- Extension dibundel bersama Selesai, tetapi **tidak aktif kecuali `rtk` terpasang**.
- `rtk` harus tersedia di `PATH` dan melaporkan versi `0.23.0` atau lebih baru (`rtk rewrite` diperkenalkan di `0.23.0`).
- Jika `rtk` tidak ada, lebih tua dari `0.23.0`, atau versinya tidak dapat diparse, extension mencetak peringatan dan tidak melakukan apa pun.

## Yang disiapkan

- Probe `rtk --version` saat extension dimuat dan keluar jika binary tidak ada atau terlalu tua.
- Mendaftarkan listener `tool_call` yang mencegat Bash tool call dan mendelegasikan penulisan ulang command ke `rtk rewrite`.
- Menerapkan command yang ditulis ulang hanya ketika `rtk rewrite` keluar dengan kode `0` atau `3` dan mengembalikan stdout non-kosong yang berbeda dari command asli.

## Yang dapat dikonfigurasi

| Environment variable | Efek |
| --- | --- |
| `RTK_DISABLED=1` | Menonaktifkan extension sepenuhnya, bahkan saat `rtk` terpasang. |

Tidak ada file konfigurasi atau setting key khusus Selesai. Extension sengaja dibuat tipis; semua aturan rewrite berada di registry binary `rtk`.

## Yang dapat dilakukan

- Pasang `rtk >= 0.23.0` di `PATH` shell Anda, lalu jalankan Selesai. Tool call `bash` yang kompatibel ditulis ulang secara otomatis.
- Setel `RTK_DISABLED=1` sebelum menjalankan Selesai untuk melewati rewriter.
- Periksa command yang ditulis ulang di output tool jika model meminta perilaku shell yang tepat.

## Perintah, tool, dan shortcut

Tidak ada slash command, tool, atau shortcut. Extension hanya menulis ulang Bash tool call.

| Mekanisme | Deskripsi |
| --- | --- |
| `rtk rewrite <cmd>` | Subproses eksternal yang mengembalikan ekuivalen yang lebih tenang atau menandakan tidak ada rewrite. |
| Hook Bash tool call | Mencegat tool call `bash` sebelum eksekusi. |

## Batasan dan keamanan

- Hanya tool call `bash` yang ditulis ulang; tool lain tidak tersentuh.
- Command yang sudah diawali `rtk ` dilewati untuk menghindari rekursi.
- Rewrite bersifat advisory: jika `rtk rewrite` keluar dengan kode tak terduga, timeout setelah 2 detik, atau melempar error, command asli tetap berjalan (fail-open).
- Extension tidak menambahkan tool baru atau mengubah perilaku model; hanya mengubah string command yang diteruskan ke Bash.
- Pasang dan kelola `rtk` secara terpisah; Selesai tidak membundelnya.
