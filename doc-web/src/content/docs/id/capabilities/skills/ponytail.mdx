## Apa ini dan mengapa membantu

`ponytail` adalah keluarga mode komunikasi dan helper review yang membuat respons agent menjadi minimal, terkompresi, dan fokus. Panggil dengan `/skill:ponytail` atau varian terkait seperti `/skill:ponytail-review`, `/skill:ponytail-audit`, `/skill:ponytail-gain`, `/skill:ponytail-debt`, dan `/skill:ponytail-help`.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai extension `ponytail` dan skill `ponytail*` di `src/skills/`.

## Mulai cepat

```sh
/skill:ponytail
```

Untuk review:

```sh
/skill:ponytail-review
```

## Konfigurasi

Tidak diperlukan konfigurasi terpisah. Skill ini mengubah cara agent memformat dan menentukan cakupan respons.

## Batasan dan edge case

- Mode ponytail mengurangi verbositas; penjelasan kompleks mungkin perlu diminta secara eksplisit.
- Varian disesuaikan untuk task tertentu; pilih varian yang cocok dengan tujuan saat ini.
