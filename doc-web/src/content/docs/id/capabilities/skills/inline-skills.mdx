Extension `inline-skills` memungkinkan Anda mengajak skill yang terpasang langsung di dalam pesan dengan mengetik `$skill-name`. Extension menyediakan saran autocomplete dan memperluas skill yang cocok ke dalam konteks percakapan sebelum agen berjalan.

## Penyiapan dan prasyarat

- Dibundel bersama Selesai dan dimuat otomatis.
- Hanya bekerja dengan skill yang sudah terpasang (source di `src/skills/` atau file skill user-level).
- Memerlukan sesi interaktif dengan editor autocomplete; penggunaan headless atau non-TUI masih memperluas token `$skill-name` yang sudah diketik.

## Yang disiapkan

- Mendaftarkan autocomplete provider yang dipicu oleh `$`. Saat Anda mengetik, provider menyarankan nama skill terpasang yang mengandung token tersebut.
- Hook event `input` untuk memperluas setiap token `$skill-name` menjadi blok `<skill>` yang ditambahkan sebelum pesan asli.
- Membaca file source setiap skill dari path yang tercatat oleh skill loader dan menghapus frontmatter-nya.

## Yang dapat dilakukan

- Mulai mengetik `$` di editor untuk melihat saran skill terpasang.
- Terima saran untuk menyisipkan `$skill-name` sebagai teks.
- Kirim pesan. Sebelum agen berjalan, extension mengganti token inline dengan blok `<skill>` skill tersebut.
- Sebutkan beberapa skill dalam satu pesan: `$grill-me $implanger` akan memperluas keduanya jika terpasang.

## Perintah, tool, dan shortcut

Tidak ada slash command, tool, atau shortcut. Permukaan extension adalah:

| Permukaan | Perilaku |
| --- | --- |
| Autocomplete `$<token>` | Menyarankan skill terpasang yang cocok dengan `<token>`. |
| `$<skill-name>` dalam pesan | Memperluas body skill yang cocok ke dalam konteks. |

## Batasan dan keamanan

- Skill inline hanya diperluas jika skill terpasang dan `sourceInfo.path`-nya dapat dibaca. Skill yang tidak tersedia atau tidak terbaca dilewati secara diam-diam.
- Setiap skill berbeda diperluas paling banyak sekali per pesan, meskipun Anda menyebutkannya beberapa kali.
- Pencocokan bersifat case-insensitive dan menerima nama skill dengan huruf kecil, angka, dan tanda hubung.
- Token skill inline harus didahului oleh word boundary atau whitespace dan diikuti oleh karakter non-identifier (spasi, tanda baca, akhir baris) untuk dikenali.
- Ekspansi adalah transformasi sebelum pengiriman; tidak menambahkan skill sebagai instruksi sesi persisten dan tidak mengubah tool set model.
- Jika input berasal dari extension lain (`event.source === "extension"`), transform dilewati untuk menghindari loop.
