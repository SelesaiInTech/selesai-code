# Skill inline

## Apa ini dan mengapa membantu

Extension `inline-skills` memungkinkan agent menerima ajakan skill ringan secara inline, tanpa file skill terpisah di project. Ini menurunkan hambatan untuk penggunaan skill sekali pakai.

## Ketersediaan

Termasuk dalam `@selesai/code` sebagai `src/extensions/inline-skills.ts`.

## Mulai cepat

```text
Use the inline skills interface to adopt a concise review skill for this diff.
```

## Konfigurasi

Tidak diperlukan konfigurasi terpisah. Skill inline diterima melalui lapisan interaksi agent normal.

## Batasan dan edge case

- Skill inline bersifat sementara; perilaku skill persisten tetap harus menggunakan `src/skills/` atau file skill tingkat user.
- Extension ini memvalidasi ajakan skill sebelum menerapkannya.
- Tidak semua skill dapat digunakan secara inline; skill multi-file kompleks masih memerlukan definisi skill lengkap.
