Riwayat ini mengikuti tag rilis Selesai yang dapat dijangkau dari branch `main`. Tag dari riwayat Pi yang tidak terkait tidak disertakan. Mulai 0.8.0, Selesai memakai tag `selesai-v*` untuk menghindari benturan dengan tag Pi yang diimpor.

## 0.8.0 — Inbox Powerline, workspace terminal fleksibel, dan setup lebih lancar

- Memperbarui fork `pi-powerline-footer` bawaan hingga upstream 0.12.3. Kini tersedia queue/inbox berbasis file (`# <idea>`, `/idea`, `/ideas`, `/queue`), pengiriman aman setelah compaction, perpindahan direktori sesi dengan `/cd`, tampilan biaya mata uang dan subagent, ikon host git, statistik token tercache, serta layout, penempatan, separator, segmen, dan welcome overlay footer yang dapat dikonfigurasi.
- Mention inline `#nama-agent` yang dikenal kini dapat memulai run subagent dari bagian mana pun dalam pesan; hash biasa di tengah pesan seperti `issue #42` tetap menjadi teks normal.
- Menambahkan setup dan panduan Agent Browser bawaan. Selesai meminta persetujuan sebelum memasang CLI eksternal dan menjalankan setup tanpa memblokir startup.
- Memperbaiki keandalan completion inline `#`/`$`, termasuk pada WSL, dan menunda provisioning RTK hingga startup selesai.

## 0.7.0 — Skill inline (`$`), subagent inline (`#`), RTK terkelola, dan Subagents 0.41

- Skill kini dipanggil inline dengan `$nama-skill` (mis. `$grill-me`, `$pdf-tools extract`) menggantikan `#nama-skill`; mengetik `$` membuka pemilih skill dan teks setelah token tetap berada di pesan pengguna. Command slash `/skill:nama` dan pengaturan `enableSkillCommands` dihapus — daftar command `/` kini hanya menampilkan extension, prompt template, dan command bawaan.
- Subagent dipanggil inline: `#nama-agent` di awal pesan menjalankan agen tersebut secara langsung (seperti `/run`), dan `#` melengkapi agen yang terinstal secara otomatis. Nama yang tidak dikenal atau ambigu menghasilkan notifikasi dan input dikonsumsi.
- Extension `rtk` bawaan kini menyediakan binary terkelola terverifikasi (pin `0.42.4`, diverifikasi checksum) saat tidak ada binary sistem yang layak, dan memakai ulang PATH jika ada; `PI_OFFLINE=1` mencegah pengunduhan dan `RTK_DISABLED=1` melewati penulisan ulang serta instalasi terkelola.
- Memperbarui Pi Subagents bawaan melalui 0.41.0 dengan streaming status `subagent_wait` langsung, jadwal proyek tahan lama, langganan wait non-blocking, ringkasan hasil inline satu baris, tampilan model/thinking FleetView, dan progress chat workflow.
- Model subagent bawaan kini memakai budget thinking Token-In (`kimi-k3:high`, `deepseek-v4-flash:max`).

## 0.6.3 — Perbaikan instalasi: pin Readability ke 0.6.0 yang terbit

- Memperbaiki instalasi package: manifest root dan `pi-web-agent` bawaan mendeklarasikan `@mozilla/readability` `^0.6.1`, tetapi registry npm tidak menerbitkan 0.6.1 (terbaru adalah 0.6.0), sehingga instalasi baru 0.6.2 gagal dengan `ETARGET`. Kedua manifest kini mendeklarasikan `^0.6.0` dan lockfile root me-resolve rilis 0.6.0 yang terbit, sehingga instalasi bersih kembali berhasil.

## 0.6.2 — Output terminal reference-first dan seeding skill/pengaturan yang aman

- Menjadikan output terminal foreground reference-first untuk hasil delegasi: renderer tidak lagi membaca ulang atau meng-inline ulang file output child yang tersimpan; hasil file-only yang settled menampilkan referensi output tersimpan, hasil legacy yang hanya memiliki path mendapat referensi sintetis tanpa menyentuh file, dan hasil `outputMode: "inline"` tetap menampilkan teks lengkapnya.
- Menjadikan seeding skill dan pengaturan bawaan aman: bootstrap saat first run menambahkan kunci `subagents` tingkat-atas yang hilang ke `settings.json` pengguna yang sudah ada tanpa mengubah format atau menyentuh pengaturan lain, tidak pernah menimpa `subagents` yang dikonfigurasi pengguna, dan menginstal skill bawaan baru (termasuk `pi-subagents`) tanpa menimpa file skill yang diedit pengguna.
- Mengirimkan skill delegasi sebagai skill bawaan tingkat-atas: `pi-subagents` kini dimuat dari package saat boot dan di-seed ke direktori agent saat first run, sehingga panduan orkestrasi parent tersedia tanpa bergantung pada salinan internal extension.
- Menyelaraskan rentang `@mozilla/readability` pada manifest web-agent bawaan ke `^0.6.1`, sesuai dengan versi yang di-resolve di package root.

## 0.6.1 — Katalog delegasi, advisory routing, dan hasil reference-first

- Menambahkan katalog delegasi runtime: `subagent({ action: "list" })` kini menampilkan agen yang executable dan yang dibatasi capability ceiling beserta source, alias, peran, konteks, tool, dan deskripsi, plus katalog yang sama sebagai metadata mesin ber-version (`details.catalog`).
- Menambahkan advisory routing berbasis tugas: berikan `task` opsional pada `action: "list"` untuk mendapatkan rekomendasi satu agen kanonik (implementation atau read-only), atau panduan ketika intent tidak jelas atau tidak ada kandidat yang aman. Saran tidak pernah meluncurkan pekerjaan — eksekusi tetap panggilan eksplisit terpisah.
- Menjadikan hasil delegasi reference-first secara default: penyelesaian mengembalikan referensi output tersimpan plus status/informasi lifecycle, bukan prosa child; output penuh tersedia melalui path output tersimpan, status/transkrip async, atau `resume`. `outputMode: "inline"` memulihkan pengiriman inline lama, `output: false` menonaktifkan persistensi output tahan lama, dan artifact debug per-child tetap opt-in.
- Menambahkan panduan delegasi yang selalu terlihat: system prompt default maupun custom kini memuat kontrak delegasi (periksa katalog sebelum memilih; pertahankan pembacaan kecil secara lokal; delegasikan investigasi lokal yang luas, pekerjaan eksternal, dan mutasi; parent tetap pengambil keputusan dan penulis tunggal).
- Mengoreksi dokumentasi dan kontrak subagent bawaan: enam peran builtin dengan default konteks fresh/fork yang akurat, path discovery `.selesai`, instruksi builder yang dapat dieksekusi, serta peran read-only/writer yang dideklarasikan.

## 0.5.29 — Fondasi Pi 0.83 dan koordinasi lebih kuat

- Menyinkronkan fondasi coding-agent dan dependency runtime Pi exact dari 0.81.1 ke 0.83.0, termasuk perbaikan provider, katalog model, RPC bash, sesi, pemuatan resource, dan terminal.
- Menambahkan `selesai auth print-api-key` dan `selesai auth print-bearer-token` untuk mengekspor kredensial terkonfigurasi secara eksplisit ke client eksternal, dengan refresh OAuth dan kontrol masa berlaku minimum.
- Mengekspos model yang di-scope ke extension serta metadata model/sesi `PI_SESSION_*` ke tool bash yang dapat dipanggil LLM.
- Memperbarui integrasi llama.cpp dengan katalog model persisten, penghitungan penggunaan streaming, dan batas konteks yang dilaporkan server.
- Memperbarui Pi Subagents bawaan hingga 0.40.0 dengan steer/stop fleet, capability ceiling, checkpoint, usage budget, dan status runtime yang lebih kaya.
- Memperbarui Pi Intercom bawaan hingga 0.9.2 dengan identitas stabil, discovery berbasis cwd, queued delivery, diagnostik pengiriman, dan hardening broker lokal.
