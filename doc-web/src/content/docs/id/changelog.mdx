## 0.5.22 — Situs dokumentasi awal

- Meluncurkan situs dokumentasi Selesai di [GitHub Pages](https://selesaiintech.github.io/selesai-docs/).
- Mendokumentasikan 17 kemampuan user-facing yang dibundel dalam bahasa Inggris dan Indonesia.
- Menambahkan perbandingan dengan Pi coding agent asli yang berbasis bukti.
- Menyertakan pencarian lokal Pagefind, mode gelap/terang, navigasi aksesibel, dan komponen instal yang dapat disalin.
- Menambahkan skrip validasi konten dan validasi tautan hasil build.
- Mengkonfigurasi deployment GitHub Actions Pages.
