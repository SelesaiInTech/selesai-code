Riwayat ini mengikuti tag rilis Selesai yang dapat dijangkau dari branch `main`. Tag dari riwayat Pi yang tidak terkait tidak disertakan. Mulai 0.8.0, Selesai memakai tag `selesai-v*` untuk menghindari benturan dengan tag Pi yang diimpor.

## 0.9.5 — Pertanyaan di luar TUI

- Tool `question` bawaan kini berfungsi di mode non-TUI seperti host RPC/VS Code: pertanyaan dijawab melalui dialog `extension_ui_request` host alih-alih memunculkan error khusus TUI.
- Pertanyaan multiselect tetap mempertahankan multi-seleksi penuh di host yang mendukung method UI `multiselect` baru; host lama beralih ke satu pilihan.
- Klien RPC kini dapat menangani request `method: "multiselect"` dan membalas dengan array `values`.

## 0.9.4 — Workflow pi-subagents yang dapat diperluas

- Extension `/workflow-*` bawaan kini menjadi adaptor tipis berbasis registry di atas orkestrasi pi-subagents, sehingga mode milik source dapat memakai run berurutan, discovery paralel, atau loop kondisional berskrip tanpa menambah plumbing command baru.
- Workflow prototype kini menjalankan riset eksternal dan eksplorasi codebase secara paralel.
- Loop build/review/fix selesai hanya saat reviewer melaporkan `clean` dan tidak ada bagian `Remaining work:`, mencegah penyelesaian prematur pada rencana bertahap.

## 0.9.3 — Identitas model Token-In

- Mengganti identifier `auto`/`auto-premium` yang telah dihapus provider dengan model bawaan `celestial-pro`, `celestial-max`, dan `celestial-ultra`.
- Default pabrik dan injeksi prompt model kini menargetkan identifier Celestial yang didukung.

## 0.9.2 — Ketersediaan model premium Token-In

- Memulihkan model bawaan `tokenin/auto-premium` agar pilihan model premium yang sudah ada tetap berfungsi; default tetap `tokenin/auto:max` yang didukung.

## 0.9.1 — Hotfix model default Token-In

- Sesi utama dan peran subagent inti kini menggunakan model `tokenin/auto:max` yang didukung, bukan model `tokenin/auto-premium:max` yang telah dihapus.
- Jendela konteks model Token-In `auto` bawaan kini 384K.

## 0.8.9 — Model `auto` Token-In

- Default penyedia Token-In kini menyertakan model **`auto`**. Model ini berkemampuan penalaran dengan jendela konteks 512K dan 64K token maksimum; peta level thinking-nya meneruskan setiap anggaran thinking (`minimal` sampai `xhigh` mengarah ke default penyedia, `max` memetakan ke `"max"`) memakai format thinking deepseek, sehingga penyedia dapat memilih otomatis model terbaik yang tersedia untuk setiap permintaan.

## 0.8.8 — Tema saat mulai, unduhan tool yang lebih senyap, dan Pi 0.84.2

- Flag CLI baru `--use-theme <name>` mengatur tema interaktif awal untuk satu sesi, dan controller tema fullscreen kini menerapkan tema tingkat-invokasi sebelum pengaturan dimuat. TUI mendapat penyorot pencarian transkrip langsung (bisa diatur temanya lewat warna opsional baru `searchMatchBg`/`searchMatchText` yang kembali ke `selectedBg`/`text`).
- `/settings` kini memiliki opsi **Fullscreen exit output**: saat keluar dari mode fullscreen bisa mencetak transkrip seperti sebelumnya atau hanya petunjuk resume sesi (`fullscreenExitOutput`, default `"transcript"`).
- Pengaturan baru `defaultTools` mengisi pemilihan tool bawaan awal (`read`, `bash`, `edit`, `write`) untuk `createAgentSession`, sehingga SDK mulai hanya dengan tool yang Anda inginkan.
- Unduhan tool terkelola (`fd`/`rg`) dipindah dari jalur startup: TUI terpasang dan tetap responsif selama pemasangan, serta progress/pun mengalir sebagai baris status chat, bukan output konsol mentah.
- Output tool yang besar kini menampilkan pratinjau 10 baris pertama dengan petunjuk expand `... (N more lines)` inline alih-alih membuang seluruh blok.
- Penyegaran katalog model dibagi: penyegaran interaktif yang bersamaan memakai satu refresh dalam perjalanan sambil menjaga pembatalan tiap pemanggil tetap independen, serta dibatasi timeout singkat.
- Sampling tool strict eksperimental diaktifkan di bawah `PI_EXPERIMENTAL=1` (`json_schema` / `strict: "prefer"`) untuk tool bawaan read/edit/write/bash.
- `sendUserMessage` kini punya opsi `expandPromptTemplates` untuk mengirim perintah ekstensi, skill, dan template prompt dari ekstensi.
- Fondasi coding-agent dan dependensi runtime Pi yang tepat diperbarui ke 0.84.2.

## 0.8.7 — Prompt model lebih ramping dan Pi Subagents 0.50

- Permukaan tool yang dibaca model kini lebih kecil di setiap permintaan: deskripsi per-field pada skema dipangkas di wire secara default (`pruneToolDescriptions`, bisa dimatikan lewat pengaturan), deskripsi tool subagent memakai varian compact (~3 KB lebih kecil per giliran model), dan blok dokumen Pi di system prompt menyusut menjadi dua baris.
- Pi Subagents bawaan diperbarui hingga upstream 0.50.0 dengan lapisan fork Selesai (branding, routing `.selesai`, env var `SELESAI_SUBAGENT*`, mode `chain`/`tasks` deklaratif, auto-relaunch workflow).
- Ekstensi bawaan baru `model-prompt-injector` menyuntikkan prompt spesifik model ke dalam system prompt; mendukung mode `prepend`, `append`, dan `replace`.
- Memperbarui katalog konfigurasi pi-subagents: `toolDescriptionMode` kini mencantumkan default compact.
- Memperbaiki suite pengujian prompt-runtime subagent agar lulus saat dijalankan di dalam lingkungan child subagent (env var steer dibersihkan).

## 0.8.6 — Workflow me-relaunch otomatis dan visibilitas goal

- Empat mode `/workflow-*` (task, prototype, quicktype, loop) kini berjalan sepenuhnya tanpa pengawasan: saat workflow berskrip menghabiskan budget fan-out per-run sebelum goal bersih, executor async membuat budget baru dan menjalankan ulang script yang sama dengan mission dan progress file yang sama, hingga `maxWorkflowAutoRelaunches` (default 12; `0` = tak terbatas). Hanya hasil `budget` yang me-relaunch — kegagalan child yang nyata tetap langsung muncul.
- Setiap peluncuran `/workflow-*` memancarkan goal-nya di awal (terlihat di emit workflow `subagent status`) dan menamai mission yang dibuat otomatis sesuai goal (`mission.list` / `mission.show`).
- Loop build→review→fix kini bekerja dalam irisan terbatas: builder mengimplementasikan satu langkah kecil yang mandiri per putaran alih-alih seluruh rencana, dengan timeout per-run (build/fix 45m, review 15m).
- Review dibatasi pada ledger progress: builder menambahkan entri `## Round N` (file, ringkasan, validasi) ke `.pi-subagents/progress/<mode>.md`, dan commentator hanya meninjau putaran terbaru plus entri fix sebelumnya, dengan fallback ke diff penuh yang belum di-commit saat ledger tidak ada. Review yang blocking mencantumkan catatan `Remaining work:` yang menjadi benih putaran build berikutnya — umpan balik review sebelumnya kini benar-benar sampai ke builder berikutnya.
- Prompt pi-subagents bawaan (`review-loop.md`, `parallel-*.md`, `gather-context-and-clarify.md`) kini dimuat melalui `resources_discover`; prompt `workflow-drive.md` dihapus karena digantikan oleh auto-relaunch.
- Memperbarui panduan kemampuan delegasi (EN/ID) dan katalog konfigurasi pi-subagents dengan `maxWorkflowAutoRelaunches`.

## 0.8.5 — Reset pabrik pengaturan, instalasi lebih sederhana, dan instal dari repositori

- Perintah slash baru `/settings-factory-reset`: memberi peringatan sebelum mengganti `~/.selesai/agent/settings.json` dengan default pabrik bawaan, menyimpan cadangan `settings.json.bak`, tidak menyentuh kredensial (`auth.json`), sesi, ekstensi, skill, maupun tema, dan memuat ulang pengaturan secara langsung.
- Panduan instalasi kini satu perintah sederhana: `npm install -g @selesai/code`. Saran `--ignore-scripts` lama dihapus karena `@ast-grep/cli` (dependensi runtime) membutuhkan script instalasinya untuk mengunduh binary platform.
- Kini Anda dapat memasang langsung dari repositori publik — `npm install -g github:SelesaiInTech/selesai-code` membangun `main` terbaru dari source (package kini memiliki script build `prepare`).
- Default bawaan kini menetapkan `retry.maxRetries` ke 7.

## 0.8.4 — Progress workflow langsung pada peluncuran slash

- Workflow berskrip yang diluncurkan lewat slash kini menampilkan kartu progress langsung (status per child, fase, dan durasi) alih-alih placeholder "Running…" yang statis. Jembatan slash pi-subagents sebelumnya membuang trace workflow dan proyeksi chat-progress; kini keduanya diteruskan dan live-state slash merender snapshot berbentuk workflow, sehingga `/run` (tanpa `--bg`), `/chain`, `/parallel`, dan `/run-chain` memperbarui tampilan saat child berjalan.

## 0.8.3 — TUI fullscreen native dan Pi 0.84.1

- Selesai kini secara default memakai TUI fullscreen native Pi 0.84.1: transkrip dapat digulir di viewport layar alternatif, sementara editor, status, widget ekstensi, dan footer tetap berada di dock tetap. Scroll mouse/trackpad dan `PageUp`/`PageDown`/`Home`/`End` menavigasi transkrip; `tuiMode: "regular"` atau `--tui-mode regular` digunakan untuk opt-out.
- Menghapus compositor terminal-split Powerline yang tidak didukung beserta kontrol fixed-editor, mouse-scroll, dan lompatan chat. Powerline kini menggunakan dock native melalui API ekstensi standar.
- `/settings` dapat langsung mengganti mode TUI dan mengatur scrollbar fullscreen. Runtime Pi AI, TUI, dan agent-core kini menggunakan 0.84.1.

## 0.7.0 — Skill inline (`$`), subagent inline (`#`), RTK terkelola, dan Subagents 0.41

- Skill kini dipanggil inline dengan `$nama-skill` (mis. `$grill-me`, `$pdf-tools extract`) menggantikan `#nama-skill`; mengetik `$` membuka pemilih skill dan teks setelah token tetap berada di pesan pengguna. Command slash `/skill:nama` dan pengaturan `enableSkillCommands` dihapus — daftar command `/` kini hanya menampilkan extension, prompt template, dan command bawaan.
- Subagent dipanggil inline: `#nama-agent` di awal pesan menjalankan agen tersebut secara langsung (seperti `/run`), dan `#` melengkapi agen yang terinstal secara otomatis. Nama yang tidak dikenal atau ambigu menghasilkan notifikasi dan input dikonsumsi.
- Extension `rtk` bawaan kini menyediakan binary terkelola terverifikasi (pin `0.42.4`, diverifikasi checksum) saat tidak ada binary sistem yang layak, dan memakai ulang PATH jika ada; `PI_OFFLINE=1` mencegah pengunduhan dan `RTK_DISABLED=1` melewati penulisan ulang serta instalasi terkelola.
- Memperbarui Pi Subagents bawaan melalui 0.41.0 dengan streaming status `subagent_wait` langsung, jadwal proyek tahan lama, langganan wait non-blocking, ringkasan hasil inline satu baris, tampilan model/thinking FleetView, dan progress chat workflow.
- Model subagent bawaan kini memakai budget thinking Token-In (`kimi-k3:high`, `deepseek-v4-flash:max`).

## 0.6.3 — Perbaikan instalasi: pin Readability ke 0.6.0 yang terbit

- Memperbaiki instalasi package: manifest root dan `pi-web-agent` bawaan mendeklarasikan `@mozilla/readability` `^0.6.1`, tetapi registry npm tidak menerbitkan 0.6.1 (terbaru adalah 0.6.0), sehingga instalasi baru 0.6.2 gagal dengan `ETARGET`. Kedua manifest kini mendeklarasikan `^0.6.0` dan lockfile root me-resolve rilis 0.6.0 yang terbit, sehingga instalasi bersih kembali berhasil.

## 0.6.2 — Output terminal reference-first dan seeding skill/pengaturan yang aman

- Menjadikan output terminal foreground reference-first untuk hasil delegasi: renderer tidak lagi membaca ulang atau meng-inline ulang file output child yang tersimpan; hasil file-only yang settled menampilkan referensi output tersimpan, hasil legacy yang hanya memiliki path mendapat referensi sintetis tanpa menyentuh file, dan hasil `outputMode: "inline"` tetap menampilkan teks lengkapnya.
- Menjadikan seeding skill dan pengaturan bawaan aman: bootstrap saat first run menambahkan kunci `subagents` tingkat-atas yang hilang ke `settings.json` pengguna yang sudah ada tanpa mengubah format atau menyentuh pengaturan lain, tidak pernah menimpa `subagents` yang dikonfigurasi pengguna, dan menginstal skill bawaan baru (termasuk `pi-subagents`) tanpa menimpa file skill yang diedit pengguna.
- Mengirimkan skill delegasi sebagai skill bawaan tingkat-atas: `pi-subagents` kini dimuat dari package saat boot dan di-seed ke direktori agent saat first run, sehingga panduan orkestrasi parent tersedia tanpa bergantung pada salinan internal extension.
- Menyelaraskan rentang `@mozilla/readability` pada manifest web-agent bawaan ke `^0.6.1`, sesuai dengan versi yang di-resolve di package root.

## 0.6.1 — Katalog delegasi, advisory routing, dan hasil reference-first

- Menambahkan katalog delegasi runtime: `subagent({ action: "list" })` kini menampilkan agen yang executable dan yang dibatasi capability ceiling beserta source, alias, peran, konteks, tool, dan deskripsi, plus katalog yang sama sebagai metadata mesin ber-version (`details.catalog`).
- Menambahkan advisory routing berbasis tugas: berikan `task` opsional pada `action: "list"` untuk mendapatkan rekomendasi satu agen kanonik (implementation atau read-only), atau panduan ketika intent tidak jelas atau tidak ada kandidat yang aman. Saran tidak pernah meluncurkan pekerjaan — eksekusi tetap panggilan eksplisit terpisah.
- Menjadikan hasil delegasi reference-first secara default: penyelesaian mengembalikan referensi output tersimpan plus status/informasi lifecycle, bukan prosa child; output penuh tersedia melalui path output tersimpan, status/transkrip async, atau `resume`. `outputMode: "inline"` memulihkan pengiriman inline lama, `output: false` menonaktifkan persistensi output tahan lama, dan artifact debug per-child tetap opt-in.
- Menambahkan panduan delegasi yang selalu terlihat: system prompt default maupun custom kini memuat kontrak delegasi (periksa katalog sebelum memilih; pertahankan pembacaan kecil secara lokal; delegasikan investigasi lokal yang luas, pekerjaan eksternal, dan mutasi; parent tetap pengambil keputusan dan penulis tunggal).
- Mengoreksi dokumentasi dan kontrak subagent bawaan: enam peran builtin dengan default konteks fresh/fork yang akurat, path discovery `.selesai`, instruksi builder yang dapat dieksekusi, serta peran read-only/writer yang dideklarasikan.
