# Changelog

## 0.5.22 — Initial documentation site

- Launched the Selesai documentation site at [GitHub Pages](https://selesaiintech.github.io/selesai-docs/).
- Documented all 17 bundled user-facing capabilities in English and Indonesian.
- Added evidence-backed comparison with the original Pi coding agent.
- Included local Pagefind search, dark/light mode, accessible navigation, and a copyable install component.
- Added content validation and built-link validation scripts.
- Configured GitHub Actions Pages deployment.
