# Selesai

Selesai is a maintained, extension-first fork of the [Pi coding agent](https://github.com/earendil-works/pi). It keeps Pi's small, hackable coding harness and ships a coordinated set of extensions, skills, and display improvements as part of the application.

The goal is simple: make a capable coding agent useful out of the box, maximize token utilization, and get better or comparable results with fewer tokens and lower cost — without asking every user to install and trust a long list of unrelated extensions.

## Install

<InstallCommand command="npm install -g --ignore-scripts @selesai/code" />

Then run:

<InstallCommand command="selesai" />

For a one-off run:

<InstallCommand command="npx @selesai/code" />

## Start using Selesai

```sh
# Ask a question
selesai "Explain this repository and tell me how to run its checks"

# One-off review
selesai -p "Review the current git diff without editing files"
```
